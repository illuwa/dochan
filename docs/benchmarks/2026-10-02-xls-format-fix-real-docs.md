# XLS 숫자 서식 리뷰 반영 실물 검증 (2026-10-03)

대상은 README `Supported Elements`의 XLS `날짜/숫자 서식` 칸이다. 비교 기준은 v1.12.0과 리뷰 반영본이다. XLS/XLSX 짝 출력은 두 형식이 같은 서식기를 사용하므로 보조 지표로만 사용했다. 주 기준은 공개 POI 파일 안에 Excel이 저장한 `TEXT()` 수식 캐시와 `54686_fraction_formats.txt`의 표시 문자열이다. 분수 표의 열 너비 맞춤 공백은 Markdown 표시 계약에 없으므로 공백을 제거해 비교했고, 원문 공백까지 같은 경우도 별도로 셌다.

`TEXT()` 캐시는 `NumberFormatTests.xlsx`, `DateFormatTests.xlsx`, `ElapsedFormatTests.xlsx`, `FormatChoiceTests.xlsx`, `FormatConditionTests.xlsx`, `GeneralFormatTests.xlsx`, `TextFormatTests.xlsx`, `NumberFormatApproxTests.xlsx`, `DateFormatNumberTests.xlsx`의 832행을 모두 검사했다. 이 중 숫자 입력은 802행이고 비숫자 입력은 30행(불리언 20행·문자열 10행)이다. 비숫자 입력에는 숫자 서식기를 적용하지 않았다. 최종본의 573행은 Excel 캐시와 다르므로 정확 일치로 세지 않았다. 원시 값 폴백 91행도 정확 일치로 세지 않았다. 날짜·시각 서식으로 분류된 43행 중 27행은 Excel 캐시와 다르고, 이 가운데 19행은 ISO 표기로 정규화된 출력과 Excel 표시가 다른 사례다. 나머지 8행은 원시 값 폴백 등의 미지원 사례이므로 ISO 계약 차이로 세지 않았다.

분수 표의 총 3,540셀은 v1.12.0에서 30셀, 수정본에서 3,424셀이 공백 정규화 후 일치했다. 개선은 3,394셀이고 기존 일치의 회귀는 0셀이다. 공백까지 포함한 표시 문자열을 양끝만 자른 정확 일치는 2,112셀이다. 남은 116셀은 모두 가변 분모이다. 고정 분모에는 남은 불일치가 없다.

공개 XLS 720개와 XLSX 352개의 전체 Markdown SHA-256을 v1.12.0과 비교한 이전 집계는 XLS 553개 유지·167개 변경, XLSX 328개 유지·24개 변경이었다. 이번 리뷰 반영본을 직전 커밋과 비교하면 XLS 704개 유지·16개 변경, XLSX 348개 유지·4개 변경이며 양쪽 파싱 실패는 0건이었다. 파일마다 Markdown 전문을 저장하지 않고 SHA-256과 길이·오류 요약만 저장했다.

XLS 원시 셀 705,679개 중 174,746개 표시 해시가 바뀌었다. 서식별로 통화·회계 81,754, 일반 소수 83,634, 분수 3,512, 백분율 2,424, 시각 1,423, 날짜 1,387, 앞자리 채움 350, General 198, 경과 시각 50, 과학 표기 14셀이다. XLSX 원시 셀 887,477개 중 2,130개 표시 해시가 바뀌었다. 서식별로 일반 소수 1,791, 통화·회계 78, General 261셀이다. 원시 셀 추출기는 XLS 39개와 XLSX 18개의 손상 파일에서 셀 좌표를 얻지 못했으므로 이 파일들은 전체 Markdown 해시에 포함하되 셀 종류별 집계에서는 제외했다. 이 57개 파일의 전체 Markdown 해시는 모두 동일했다. 암호화된 `58616.xlsx`는 복호화한 패키지를 메모리에서만 읽어 셀 해시 분류에 포함했다.

이번 리뷰의 변경 파일에 한정해 원시 숫자 셀을 직전 서식기와 비교하면 XLS는 회계·통화 28,859셀, 일반 소수 1,578셀, General·리터럴 19셀, 날짜 12셀, 시각 12셀이 달라졌다. XLSX는 회계·통화 5셀, 일반 소수 15셀, General·리터럴 5셀이 달라졌다. 이 수치는 변경 파일의 원시 숫자 셀 분류이고 전체 Markdown 변경 셀 수는 아니다. 회계 영 구역은 서식에 따라 `-` 리터럴과 통화 기호·자리 맞춤 공백을 표시한다.

공백이 포함된 조건식, 정수 `0`, 앞자리 채움, 고정 분모, BIFF5 FORMAT, 빈 서식 구역, 회계 음수·영, 통화 기호 위치와 과학 표기 지수 폭은 합성 단위 테스트로 확인했다. 특히 접두사 뒤 앞자리 넘침, 중간 0이 있는 고정 분모, `# 0/8` 폴백은 공개 Excel 저장 표시값이 없어 규칙 추론으로만 확인했다. 남은 가변 분모 116셀과 `TEXT()` 캐시 미일치 573행은 지원 한계다. 가변 분모의 공개 Excel 정답 두 사례는 예상 실패 테스트로 남겼다. 이 한계를 명시하는 조건으로 XLS `날짜/숫자 서식` 칸에 ✅를 제안한다.
