# PDF Form XObject 본문 글자 실물 검증 (2026-10-03, 리뷰 반영)

이 문서는 기능 추가 전 소스와 최종 리뷰 수정본을 같은 공개 pdf.js PDF 983개에서 비교한 결과다. 자세한 리뷰 항목별 판정은 `2026-10-02-pdf-forms-fix-real-docs.md`에 있다. README의 지원 표시는 수정하지 않았다.

독립 정답지는 PDFium `get_textpage().get_text_range()`의 문자다. 공백을 제거하고 NFKC로 정규화한 2글자 조합 빈도를 문서마다 대조한 뒤 합산했다. 읽을 수 있는 지표는 C0/C1을 포함한 Unicode `Cc`와 U+FFFD를 양쪽 텍스트에서 제외한 다음 조합을 다시 만들었다. 이 지표는 글리프의 화면 표시나 읽기 순서 전체를 증명하지 않는다. 특히 PDFium 텍스트 추출은 BBox 밖 글리프도 포함할 수 있다. 문서별 전체 출력은 저장하지 않고 해시·글자 수·오류·조합 빈도만 기록했다.

리뷰 직전 출력 해시와 최종 출력을 비교하면 Markdown과 JSON 각각 983개 중 979개가 같다. 직접 Form 글자가 없는 944개 중에는 각각 942개가 같다. 달라진 공개 표본은 `bug1974436.pdf`, `issue14847.pdf`의 링크 보류, `freeculture.pdf`의 반복 꼬리말 링크 보류에 따른 독립 URL 표기, `knockout_groups_test.pdf`의 Form BBox 밖 글자 4개 제거로 설명된다. `knockout_groups_test.pdf`의 네 Form은 BBox x 범위 0..200에 1.32 배율을 적용한다. 빠진 마지막 글리프는 변환된 오른쪽 경계보다 바깥에서 시작한다. PDFium의 텍스트 결과에는 그 글자가 남아 있어, 이 4글자에 대해서는 BBox 기하 판정을 우선했다.

링크의 기능 추가 직전 388→리뷰 직전 557 증가는 Form 글자의 기여가 0개다. 주석 경계 허용 폭이 0.00001pt에서 0.0001pt로 커진 것이 원인이다. 증가 169개 중 165개는 `freeculture.pdf`의 반복 꼬리말 URL이었다. 최종판은 기능 추가 전과 같은 0.00001pt 허용 기준을 쓰고, 0.00005pt 안쪽 침범은 보류한다. 기본·`text_tables` 결과가 같다.

내부 79쌍은 Form 글자 문서가 0개다. 최종 재측정에서 문서별 지표 변경은 0쌍이며, 표 888개·잘못된 머리말/꼬리말 0개·평균 토큰 일치율 0.9754가 유지됐다. 이는 기능의 양성 검증이 아니라 무회귀 검증이다.

안전 상한은 Form 깊이 16, 페이지별 Form 디코드 캐시 16 MiB, 확장 바이트 32 MiB, 확장 연산자 32,768개, 글자 위치 200,000개다. 자원 사전이 다른 호출자 1,000개가 같은 1 MiB Form을 호출하는 합성 테스트에서 스트림 분석은 1회만 실행됐다. 손상 Form 예외는 해당 Form 경고로 처리하고 페이지 앞뒤 본문은 보존한다.
