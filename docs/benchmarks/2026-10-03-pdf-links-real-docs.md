## 재분류와 구현 기준

보류 290건을 문서·주석별로 다시 대조했습니다. PDFium 글리프가 없는 39건, 본문 글자 좌표가 불확실한 11건, 다른 목적지가 겹친 5건, 주석 경계가 글리프 끝을 가른 235건이었습니다. 이전에 Form 글자 미추출로 분류했던 반복 꼬리말 대부분은 이제 본문에 글자가 있으며 경계 잘림으로 분류됩니다. 원인을 PDFium 결과와 native 조각의 중심 좌표로 판정했고, 파일명이나 페이지 수에 따른 임의 예외는 넣지 않았습니다.

경계 잘림 235건 중 211건만 연결했습니다. 선택할 글리프 중심은 사각형 또는 QuadPoints 안에 있어야 하고, 글리프의 한쪽 끝만 잘려야 합니다. 바깥쪽 이웃 글자가 같은 목적지로 선택되거나 공백·괄호·문장 부호 구분자 없이 이어지면 보류합니다. 이웃 글자는 같은 조각뿐 아니라 같은 기준선에서 맞닿은 다른 조각(TJ 분할·별도 Tj)에서도 찾습니다. 중심은 밖인데 글리프 끝만 안에 있거나 양 끝이 모두 밖인 경우도 보류합니다. 서로 다른 목적지가 같은 글자를 선택하면 보류합니다. 댓글 주석 앵커에는 기존 보수적 조건을 적용해 링크 변경이 댓글 출력을 바꾸지 않게 했습니다. 최종 79건은 실제 글자 없는 39건, 불확실한 좌표 11건, 다른 목적지 겹침 5건, 남은 경계 잘림 24건입니다.

`quadpoints.pdf`와 `bug1974436.pdf`의 QuadPoints 보류 각 1건은 독립 글리프와 일치해 새로 연결됐습니다. 별도의 Form 전용 예외는 필요하지 않았습니다. `freeculture.pdf`에서는 본문 링크가 있는 페이지·목적지 수가 1건에서 167건으로 늘고, 대체 링크 문단 수는 170건에서 4건으로 줄었습니다. 같은 페이지·목적지의 본문 링크와 대체 문단 중복은 수정 전후 모두 0건이었습니다. 따라서 본문 연결이 되면 기존 최종화 경로가 대체 문단을 억제하며 별도 출력 모델 변경은 필요하지 않습니다.

## 회귀와 출력 해시

기본·`text_tables`의 678개 주석별 판정과 연결 글자·URL이 서로 같습니다. 기존 연결 388건은 주석별 글자와 URL이 388/388건 정확히 동일합니다. 새 연결 211건은 독립 PDFium 또는 비유니코드 보조 기준과 211/211건 일치합니다. 두 모드 모두 경계 불일치, URL 출력 유실, 최종 런 불일치, 프로브 오류가 0건입니다.

공개 983개에서 Markdown과 JSON의 SHA-256 변화는 각 모드 모두 10문서에서만 발생했습니다. 10문서는 모두 새 본문 링크가 있는 문서입니다. 나머지 973문서는 두 출력 해시가 각각 동일합니다. 전체 출력은 디스크에 저장하지 않고 해시·문자 수·오류 목록만 기록했습니다. 내부 79쌍은 기준 전후 집계 지표가 모두 같습니다. 두 경우 모두 평균 토큰 일치율 0.9754, 줄 결합 정확도 0.9378, PDF 표 888개, 머리말·꼬리말 오탐 0개, 표 구조 일치율 0.6533, 병합 일치율 0.9277, 중첩 일치율 0.3939입니다. 내부 문서의 파일명이나 내용은 기록하지 않았습니다.

합성 테스트는 잘린 글리프의 안전한 연결, 이어진 단어의 보류, 괄호 구분자, 양 끝 밖의 좁은 영역, 중심 밖/끝 안쪽, 여러 줄 QuadPoints, 댓글 앵커 불변, 본문 연결 시 대체 문단 제거를 확인합니다. 기준 사본의 전체 테스트와 현재 워크트리의 전체 테스트 결과는 최종 작업 보고서에 별도로 기록합니다.

## 감수 후속 — 조각 경계의 이웃 글자(2026-10-03)

감수에서 잘린 경계의 이웃 글자 확인이 조각 안에서만 적용된다는 지적이 나왔다. `[(exam) 0 (ple and more)] TJ` 처럼 단어가 두 조각으로 나뉘면
`exam[ple](url)` 로 단어 일부만 연결되고 대체 URL 문단이 사라졌다. 이제 이웃 색인이 조각 밖이면 같은 기준선·같은 방향에서 끝이 맞닿은
조각을 찾는다. 맞닿음은 줄 조립과 같은 기준(겹치거나 간격이 두 조각 공백 폭 중 큰 값의 절반 이하)이며, 오른쪽 이웃은 이 조각보다 뒤에서 시작하는 조각,
왼쪽 이웃은 앞에서 시작하는 조각으로 순서를 따진다. 공백 폭이 없으면 글자 크기의 1/8 을 쓴다(가로 글꼴의 공백 폭 하한과 같은 값). 찾은 글자에 같은 확인(공백·구분자
여부, 같은 링크 소속 여부)을 적용하고, 맞닿은 조각이 없으면 단어 경계로 본다.

첫 구현은 공개 코퍼스에서 연결이 600건에서 582건으로 줄었다. 원인은 두 가지였다. 한 글자씩 그린 줄에서 앞쪽 조각을 뒤쪽 이웃으로 잘못
잡은 것(겹침 허용을 글자 크기만큼 둔 탓)과, 링크 바로 뒤 쉼표·마침표·전각 쌍점을 단어의 일부로 본 것이다. 겹침 허용을 공백 폭의 절반으로
