# 구형 HWP `Contents` 차트 실물 조사

2026년 10월 3일 공개 HWP 코퍼스를 읽기 전용으로 조사했다. 구현 근거로 검토한 명세는 한컴 「한글 문서 파일 구조 - 차트」 개정 1.2(2014-11-20)이며, 로컬 사본은 `corpus/specs/hwp-chart-rev1.2.pdf`이다. 명세 2쪽의 ChartObj 헤더와 3쪽의 객체 트리, 4쪽부터의 속성 표를 확인했다. 문서는 개별 속성의 이진 오프셋과 `VtMatrix` 셀 인덱스 예외를 규정하지 않는다.

독립 OLE 판독(`olefile`)으로 공개 문서 7개, 차트 참조 33개, 실제 저장소 33개를 확인했다. 아래 저장소 모두 루트 CLSID가 `5A721580-5AF0-11CE-8384-0020AF2337F2`이며 스트림은 `Contents` 하나뿐이다. `OlePres000`이나 다른 미리보기 WMF/EMF 스트림은 하나도 없다. 지정된 `143E433F503322BD33.hwpx` 짝에는 차트 XML이 없고 같은 `Contents` OLE인 `BinData/ole3.ole`만 있다. 따라서 요청된 두 독립 정답지로는 어떤 참조의 제목·종류·계열·범주·값도 확인할 수 없다.
