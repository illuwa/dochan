## 전수 해시와 독립 정답

공개 XLS 720파일의 정렬된 숫자 셀 705,683개 중 변경은 485개였다. 변경 서식은 `m"月"d"日"` 225개와 `d` 260개뿐이었다. XLSX 352파일의 숫자 셀 320,856개에서는 변경이 없었다. 판독 실패는 XLS 39파일, XLSX 19파일로 기준과 같았다. 해시 비교가 아닌 독립 유리수 계산으로도 변경 셀 485/485개의 결과를 확인했다.

변경된 두 서식에서 난수 시드 `20261003`으로 각각 10셀씩 뽑았다. `12843-1.xls`의 `ATM-表!I5`는 일련번호 37382에서 `5月6日`, `external_named_function.xls`의 `Zeitplan!BR2`는 일련번호 40829에서 `13`이었다. 나머지 18개 주소와 값은 `2026-10-03-date-iso-real-docs.md`에 기록했다.

## 경계와 견고성

이름 토큰(`ddd`·`dddd`·`mmm`·`mmmm`)에 시각이 섞인 형식과 이미 ISO였던 `mm-d h`는 기준 출력을 유지했다. 숫자 부분 날짜의 리터럴은 표시하며, `d "days" h:mm`은 요청된 토큰 표시 예외로 처리했다. `a/pm`·`am/p`는 Excel 오전·오후 토큰으로 인식하지 않는다. 9999년 뒤의 일련번호를 오전·오후 시각으로 감싸지 않고 원시값으로 남긴다.

닫히지 않은 따옴표 등을 포함한 고정 난수 4,000건에서 전파된 예외와 수정 전에는 없던 빈 출력이 각각 0건이었다. 서식 길이 32·64·128·255에서 1,000건당 처리 시간은 차례로 0.068·0.083·0.114·0.175초였다. 길이 255 초과는 기존대로 원시값을 유지한다. 이 수치는 처리량 관찰이며 전체 입력에 대한 복잡도 증명은 아니다.

재현은 `scripts.probe_date_iso2_delta`, `scripts.probe_date_iso2_cache`, `scripts.probe_date_iso2_oracle`, `scripts.probe_date_iso2_charts`, `scripts.probe_xls_fraction_excel`로 한다. 코퍼스 루트와 기준 서식기 또는 코드 트리는 명령 인자로 받는다. 프로브는 문서 본문을 저장하지 않고 해시·개수·오류·작은 표본만 기록한다.
