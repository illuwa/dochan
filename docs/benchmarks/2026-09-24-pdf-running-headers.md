# PDF 반복 머리글/바닥글 검증 (2026-09-24, dochan 1.6.0)

PDF 에는 머리글·바닥글이라는 구조가 없고 페이지마다 같은 자리에 같은 텍스트가 다시 그려질 뿐이다.
HWPX 정답에는 머리글이 섹션당 한 번 `HeaderFooter` 로 있고, 쪽번호 필드는 텍스트가 없는 바닥글로
남는다. 이 검증은 PDF 리더가 반복 텍스트를 머리글/바닥글로 분리해 HWPX 와 같은 위치에 한 번만 내는지
잰다. README 비교표의 PDF `머리글/바닥글` ✅ 근거다.

## 실측으로 정한 규칙 (79쌍, HWPX = 정답)

- HWPX 머리글 텍스트가 PDF 페이지의 맨 위 줄과 같은 페이지: 1,363쪽 중 1,323쪽. 그 줄의 기준선은
  위 가장자리에서 56–73 단위(중앙값 70) 아래에 있어, 표 병합에 쓰는 고정 60단위 구역 밖이다 → 구역은
  페이지 높이의 12%(A4 ≈ 101단위)로 정했다.
- 맨 아래 줄이 쪽번호만인 페이지: 1,347쪽(기준선 30–46 단위).
- 모든 숫자를 `#` 로 접는 단순 키는 `[별지 제1호 서식]`/`[별지 제2호 서식]` 같은 본문 서식 제목을
  11개 문서에서 반복 키로 오인했다 → 숫자 접기는 쪽번호형 줄(숫자·공백·`-–—·./()[]页쪽페이지Page of`
  를 빼고 3자 미만 남는 줄)에만 적용하고, 후보는 가장자리에서 이어지는 연속 블록(줄 간격 ≤ 1.5×크기,
  최대 3줄)으로 제한한다.
- 반복 임계는 `max(2, ⌈0.3 × 텍스트 페이지⌉)`. 79쌍은 모두 2쪽 이상이라 1쪽 제외 대상은 없었다.
- 독립 리뷰·감수에서 나온 코퍼스 밖 사례를 막는 규칙: 쪽번호형은 명시적 패턴(`3`, `- 3 -`, `3 / 20`,
  `Page 3`, `3쪽`, `(3)`)만 인정해 `제1조`·날짜·금액이 접히지 않게 했고, 여백이 좁아 본문 첫 줄이 상단
  12% 안에 걸리는 문서(워드 기본 여백)를 위해 가장자리 블록이 본문과 2×글자 크기 이상 떨어진 쪽이
  출현의 과반이어야 한다(79쌍에서는 5문서 6쪽만 간격 17.8–20.5pt 로 예외였고 과반 규칙으로 회수됨).
  넓은 간격의 세그먼트가 3개 이상인 표형 줄(무괘선 표 머리행)은 후보에서 뺀다. 오검출 지표 `hf_false` 는 0.

## 실행

```bash
python -m scripts.compare_pdf_pairs test_pairs/ --output out.json
```

`hwpx_hf`/`pdf_hf` 는 쪽번호형을 뺀 고유 머리글·바닥글 텍스트, `hf_hit` = |교집합| / |hwpx_hf|.

검출된 머리글 77개는 모두 문서 제목(규정·지침명)이고 HWPX 에 없는 머리글은 0개다. 놓친 것은 한
문서의 두 항목으로, 작성 안내 문구가 별도 섹션의 머리글로 들어간 경우다(PDF 본문에도 그대로 남아 있어
반복 조건을 채우지 못함). 토큰 유사도가 오른 것은 페이지마다 반복되던 제목과 쪽번호가 본문에서
빠졌기 때문이며, 내려간 쌍은 없다.

## 한계

- 1쪽 문서와 2쪽 중 1쪽에만 있는 머리글은 검출하지 않는다(반복 근거가 없음).
- 표 안에 그린 머리글, 세로쓰기·회전 페이지의 머리글은 대상이 아니다.
- 텍스트 페이지가 5,000을 넘는 문서는 검출을 생략한다(초안 보관 메모리 상한).
