# HWP·HWPX 제목 감지 후속 실물 검증

검증일은 2026년 10월 4일이다. 개발에는 `corpus/press-pairs`와 이미 판독에 사용된 `corpus/press-pairs-holdout`의 PDF 판독 라벨 372개만 사용했다. `corpus/press-pairs-holdout2`는 열거나 측정하지 않았다. 기준 소스는 작업 시작 커밋의 `git archive` 한 사본이다. 문서별 Markdown 전체는 저장하지 않고 SHA-256, 문단 경로, 제목 수준, 오류 목록을 비교했다. 차이가 난 본문도 코퍼스 파일로 복사하지 않았다.

`▷`·`◇`·`Q 2.`는 위 표본에 없었다. `▶`·`◆`의 비어 있는 모양과 같은 질문 번호 문법으로 합성 HWP/HWPX 테스트는 통과했지만, 이 변형들의 실물 정밀도는 확인하지 못했다. 굵은 `ㅇ` 항목과 `첫째, …한다.` 문장형 머리는 각각 본문 목록 및 설명 문장과 구별할 구조 근거가 부족해 규칙을 추가하지 않았다. HWPX의 `NUMBER` 문단 모양은 공개 `156783701.hwpx`에서 길고 서술적인 일반 문장에도 쓰였다. 번호 속성만으로 모든 문단을 제목으로 바꾸지 않은 이유다.

공개 HWP 전체 비교에서 표 직전 괄호 줄을 정렬과 무관하게 제외하는 초안은 제목→본문 291개를 만들었다. 그중 왼쪽 정렬된 `[ 대책 개요 ]`처럼 표 앞의 절 머리일 수 있는 줄이 있어, PDF 근거가 있는 가운데 정렬에만 캡션 규칙을 적용했다. 왼쪽 정렬 괄호 줄은 합성 회귀 테스트로 제목 판정이 유지되는지 확인했다.

## 개발 라벨 전후

독립 판독 라벨 372문단의 접두어와 문단 경로는 기준·현행 양쪽에서 모두 일치했고 건너뛴 행은 0개다. 이 묶음은 이전 규칙의 평가에 이미 사용됐으므로 이번에는 개발 자료다. 수치를 새 보류 검증으로 해석하지 않는다.

| 형식 | 양성 라벨 | 이전 TP·FP·FN | 이후 TP·FP·FN | 이전 정밀도·재현율 | 이후 정밀도·재현율 |
|---|---:|---:|---:|---:|---:|
| HWPX 310문단 | 43 | 19·4·24 | 35·0·8 | 82.6%·44.2% | 100.0%·81.4% |
| HWP 62문단 | 7 | 2·0·5 | 2·0·5 | 100.0%·28.6% | 100.0%·28.6% |
| 합계 372문단 | 50 | 21·4·29 | 37·0·13 | 84.0%·42.0% | 100.0%·74.0% |

남은 누락 13개 중 HWPX 8개는 `□` 뒤 주석이 한 문단에 붙은 줄 1개와 굵은 `ㅇ` 항목 7개다. HWP 5개는 자동 번호 1개, 이미 텍스트 번호가 있는 절 1개, 문장형 머리 3개다. 자동 번호 복원에는 번호 정의와 문단 순번 상태를 함께 읽어야 한다. 공개 HWPX의 `NUMBER` 문단도 현행 출력에서 번호가 빠질 수 있으므로, 두 리더의 번호 출력을 함께 검증하는 별도 작업이 필요하다.

## 코퍼스와 짝 비교

`scripts.probe_heading_relative`의 전후 비교는 문단 경로·제목 수준과 제목 수준을 잠시 지운 Markdown 해시를 대조했다. 다음 수치는 작업 시작점 대비 이번 변경만의 차이다.

| 형식 | 파일 | 본문→제목 | 제목→본문 | 제목 외 Markdown 변화 | 새 예외 |
|---|---:|---:|---:|---:|---:|
| HWP | 5,376 | 40 | 111 | 0 | 0 |
| HWPX | 1,700 | 29 | 97 | 0 | 0 |

합계 7,076개에서 본문→제목 69개, 제목→본문 208개다. HWPX 28개는 기준과 현행 모두 같은 예외로 읽히지 않았고 새 예외는 0개다. 문단 경로 수와 오류 목록은 전후 같았다. 가운데 정렬된 괄호 줄이 표 바로 앞에 있는 경우가 코퍼스 전체에도 많아 제목→본문 변화가 승격보다 많다. 이 208개 모두의 의미 라벨을 확인한 것은 아니므로 코퍼스 차이를 정확도 향상 수치로 해석하지 않는다.

공개 보도자료 `corpus/press-pairs`의 HWPX 346개에서는 본문→제목 29개, 제목→본문 4개이고 HWP 111개에서는 본문→제목 0개, 제목→본문 1개다. 제목 외 Markdown 해시 변경은 0개다. HWP/HWPX가 모두 있는 91쌍에서 공통 텍스트의 제목 상태 일치는 전후 모두 1,962/1,962였다. 내부 실물은 HWPX 80개·HWP 77개를 비교했고 두 형식 모두 제목 수준과 제목 외 출력의 변화가 0개다. 내부 76쌍의 공통 텍스트 제목 상태 일치는 전후 모두 9,856/9,856이었다. 내부 파일명과 내용은 기록하지 않았다.
