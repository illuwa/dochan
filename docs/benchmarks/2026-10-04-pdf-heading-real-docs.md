# PDF 같은 크기 강조 절 제목 실물 검증

## 판정과 범위

PDF의 기존 크기 기반 제목을 유지하면서, HWP·HWPX와 같은 강조 절 제목 판정을 적용했다. `heading_font.py`의 `body_font_size`, `emphasized_heading_level`, 문맥 제외 함수 `_context_exclusions`를 그대로 호출한다. 공용 `finalize_font_headings`는 기존 제목을 재계산하므로 호출하지 않는다. HWP·HWPX 및 공용 판정 구현은 변경하지 않았다. README의 `제목 감지 · PDF`는 이미 ✅이며, 이번 검증은 그 칸의 개선 근거다. README는 수정하지 않았다.

PDF 규칙의 개발 묶음은 `press-pairs-holdout`, `press-pairs-holdout2`, `press-pairs-holdout3`이다. 같은 라벨을 조정·채점에 사용했으므로 아래 점수는 독립 보류 성능이 아니다. 새 `press-pairs-holdout4`는 읽지 않았다. 라벨의 `doc`에는 HWPX뿐 아니라 HWP 확장자도 있어 같은 숫자 newsId의 PDF로 대응한다.

## 구현 계약과 굵기 근거

최상위 `Paragraph`의 실제 런 크기를 PDF 조각에서 복원하고, H1/H2가 아닌 물리적 한 줄에만 새 판정을 적용한다. 표 셀, 반복 머리말·꼬리말, 각주·미주 정의에는 적용하지 않는다. 본문 크기는 최상위 문단의 첫 가시 런 크기에 문단 길이를 가중한 최빈값이다. 공용 함수의 0.1pt 집계, 최소 3문단·40글자 조건과 주석 줄 제외를 따른다. 표 셀은 이 본문 크기 표본에도 넣지 않는다. 표본이 부족하면 새 제목을 만들지 않는다.

표지의 크기·굵기는 내용 강조의 근거에서 빼며, 공용 규칙에 따라 내용이 본문보다 크거나 허용된 표지의 내용 전체가 굵으면 H3로 올린다. 같은 크기의 번호·로마 숫자·PUA 목록은 굵기만으로 승격하지 않는다. 괄호 태그 뒤 두 어절 이상, 네모 내용 60자 초과, 화살표·연결 어미·문장 종결·콜론 등은 공용 규칙 그대로 제외한다. 표지가 없는 1.1배 H3 규칙은 추가하지 않았다.

`BaseFont` 이름의 `Bold`, `FontDescriptor`의 `ForceBold`·`FontWeight` 판정은 기존 구현을 유지했다. 한컴 실물에서는 일반 글꼴에 양수 선폭과 `Tr 2`를 적용하는 방식도 확인했다. ISO 32000-1 9.3.6의 채우기+테두리 모드 2·6에 대해서만 조각의 `bold`를 보완했다. 모드 1·5의 테두리 전용과 선폭 0의 hairline은 합성 굵기 근거로 쓰지 않는다. `q/Q` 저장·복원 및 Form 상속을 보존하며, 글꼴 객체 자체를 바꾸지 않는다. `_show`의 배율 계산은 변경하지 않았다.

PDF에는 HWP의 문단 모양 ID와 스타일 이름이 없다. 값 목록의 동일 문단 모양은 같은 들여쓰기·크기·정렬로 대신한다. 가운데 정렬은 줄 중심과 MediaBox 중심의 차이가 1.5pt 이내인지 확인한다. 이는 기존 PDF 기하의 1.5pt 허용치를 재사용한 것이다. 가운데 괄호 캡션은 출력 순서상 다음 요소가 표일 때 공용 제외를 적용하며, 그리기 순서가 뒤섞인 경우에는 아래 표까지 거리가 기존 줄 병합 거리인 글자 크기 1.8배 이내이고 중간 본문 줄이 없는지 확인한다. `156783129.pdf` 3쪽에서 캡션 뒤에 FAQ가 먼저 출력되고 표가 뒤에 나오던 사례를 이 기하 조건으로 제외했다. 스타일 이름에 따른 제외는 PDF에 근거가 없어 적용하지 않는다. 네 개 이상 점과 끝의 쪽 번호가 있는 차례 항목은 `issue14847.pdf`에서 실측한 PDF 전용 제외다.

## 개발 라벨 전후

라벨 접두어 `t`와 PDF 최상위 문단에서 공백을 제거한 뒤, PDF 문단이 접두어로 시작하거나 4글자 이상 PDF 문단이 접두어의 앞부분과 같으면 대응 후보로 삼는다. 후보가 하나인 행만 정밀도에 넣는다. 전체 제목 재현율은 대응하지 못한 제목까지 분모에 남긴다. 빈 접두어·모호 대응·없는 파일은 성공으로 세지 않는다. 채점 출력에는 집계와 공개 newsId만 남긴다.

### 본문 크기와 H3 실험

같은 굵기 복원·공용 표지 규칙·문맥 제외에서 강조 후보의 본문 크기만 쪽 중앙값으로 바꾼 실험을 했다. 또한 문서 본문 크기 대비 1.1배 H3를 표지 없이 추가하는 실험을 했다. 두 실험 모두 기존 H1/H2는 보존했다.

## 전수 회귀와 첫 제목 영향

같은 시작 커밋의 소스 스냅숏과 완성 코드로 같은 파일 집합을 읽었다. 파일마다 Markdown SHA-256·문자 수·경고 해시, 제목 문단 위치·텍스트 해시·수준, 첫 제목 해시를 저장했다. 전체 출력을 문서별로 저장하지 않았다. 본문 검사는 최상위 문단 문자열의 연결 해시이며, 표 내용·서식의 완전 동치 증명은 아니다. 제목의 크기 판정 비교는 H1/H2의 문단 위치·텍스트 해시·수준 집합으로 수행했다.

|---|---:|---:|---:|---:|---:|---:|
| 공개 pdf.js | 983 | 26 | 692→799 | 0 | 0 | 0 |
| 공개 보도자료 press-pairs | 375 | 369 | 287→804 | 111 | 104 | 0 |
| 공개 보도자료 holdout | 217 | 213 | 122→325 | 60 | 57 | 0 |
| 공개 보도자료 holdout2 | 232 | 230 | 84→404 | 75 | 67 | 0 |
| 공개 보도자료 holdout3 | 233 | 228 | 148→490 | 82 | 81 | 0 |
| 공개 LibreOffice PDF | 24 | 0 | 4→4 | 0 | 0 | 0 |
| 내부 PDF, 집계만 | 80 | 10 | 420→448 | 1 | 0 | 0 |

2,144개에서 처리 예외·시간 초과, 경고 변화, 최상위 본문 문자열 변화는 모두 0개다. 보도자료 기본 묶음은 이 작업에서 확인한 PDF 375개를 기준으로 했으며, 수집 계획 수량을 실물 수량으로 쓰지 않았다. HWP 5,363개와 HWPX 1,675개, 합계 7,038개의 Markdown SHA-256은 전후 모두 같았다.

보도자료에서는 기존 H1/H2가 없던 309문서에 첫 H3가 생겼고, 기존 제목 앞에 H3가 추가된 19문서까지 합쳐 328문서의 첫 제목이 달라졌다. 내부 PDF는 1문서의 첫 제목이 달라졌으며 원문·이름은 기록하지 않았다. 첫 제목을 무조건 문서명으로 쓰는 하류 서비스에는 이 변화가 영향을 줄 수 있다. 문서 제목 추출에서는 기존 H1/H2를 우선하고, 해당 수준이 없으면 제공된 제목이나 원래 문서명을 쓰는 정책을 제안한다. 절 제목을 숨겨 이 문제를 피하지 않았으며, 하류 서비스는 이 저장소 범위 밖이라 변경하지 않았다.

이 309문서 중 네모 표지 `□`·`■`가 첫 제목이 된 문서는 기본 묶음 62개, holdout 30개, holdout2 45개, holdout3 49개로 총 186개다. 나머지 123문서는 괄호·번호·다른 표지였다. [기계 판독용 집계](2026-10-04-pdf-heading-results.json)에 점수·newsId·회귀 집계를 함께 기록했다.

### pdf.js 렌더 판독

## 재현과 단위 테스트

다음 명령으로 같은 라벨의 점수를 집계한다. 코퍼스 경로는 실제 위치를 인자로 주며 저장소에 복사하지 않는다.

```sh
/usr/bin/python3 -m scripts.score_pdf_heading_labels \
  --labels docs/benchmarks/2026-10-04-heading-blind-labels.json --corpus corpus/press-pairs-holdout \
  --labels docs/benchmarks/2026-10-04-heading-blind-labels-2.json --corpus corpus/press-pairs-holdout2 \
  --labels docs/benchmarks/2026-10-04-heading-blind-labels-3.json --corpus corpus/press-pairs-holdout3 \
  --output .codex-work/pdf-heading-labels.json
```

`scripts/probe_pdf_heading_regression.py`에는 `--public 묶음=경로`, `--private 묶음=경로`, `--repo 이전소스`, `--output 해시기록`, `--baseline 이전해시기록`을 준다. 내부 묶음은 파일명 대신 정렬 인덱스만 남기고 본문·경고도 해시로 저장한다. HWP·HWPX 비교에는 `--format hwp --format hwpx`를 준다. 같은 인벤토리와 파일 정렬을 전후에 유지해야 한다.

합성 PDF 테스트는 `tests/test_pdf_headings.py`에 있다. 굵은 표지 승격, 보통·부분 굵기·여러 줄 비승격, 진술 제외, 기존 크기 제목 불변, 번호의 크기 조건, 작은 표지와 큰 내용, 렌더 모드·선폭, 값 목록, 표 셀·머리말·각주 제외, 표 그리기 순서가 뒤섞인 캡션, 차례 항목, 실제 런 크기와 Markdown 강조 병합, 문단 상한·메타데이터 정리, Form 상태 상속을 검증했다. 채점과 회귀 집계에는 별도 테스트가 있다. 기존 테스트의 단언은 바꾸지 않았다.
