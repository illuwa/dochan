# JSON C: str 하위 클래스 직접 이스케이프 (2026-11-04)

기준 v1.19.0 이후 main(`db894ff`) 대비. 변경은 `dochan/output/_cjson.c` 의 값 직렬화 한 줄이다. 정확한 `str` 만 C 로 쓰고
`str` 하위 클래스(XLS 리더가 셀마다 만드는 `_NumericString` 등)는 Python 폴백으로 넘기던 것을, 표준 라이브러리 인코더와 같이
저장된 문자 그대로 이스케이프한다(`PyUnicode_Check`). 하위 클래스의 `__str__`·`__len__`·`__iter__`·`encode` 같은 재정의는 부르지 않는다.
사전 키의 하위 클래스, 정수·부동소수 하위 클래스는 기존대로 폴백한다.

## 테스트 (먼저 작성, 수정 전 33개 실패)

모든 Python 훅이 예외를 내는 `str` 하위 클래스를 일반 값(목록·사전 값·루트)과 모델의 런 텍스트에 넣어, 폴백 콜백이 불리면 실패하도록 하고
표준 `json.dumps(..., indent, ensure_ascii=False)` 와 바이트 단위로 비교한다(빈 문자열, 제어문자, 서로게이트, 비BMP, U+2028, 70,000자, 들여쓰기 4종, 문자열·파일 출력).
