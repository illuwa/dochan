# HWP·HWPX 글꼴 제목의 본문 크기 상대 판정 실물 검증

## 범위와 규칙

개요 수준과 스타일 이름이 정한 제목, 깊은 개요의 본문 판정, 표 셀의 글꼴 제목 제외는 유지했다. HWP와 HWPX는 공통 스타일 이름 규칙을 사용한다. `제목` 또는 `title`이 들어간 스타일은 H1, `부제목` 또는 `subtitle`로 시작하는 스타일은 H2다. 다만 이름에 `표`·`그림`·`차례`·`목차`·`양식`이 있으면 스타일 이름만으로 제목을 만들지 않는다. HWPX의 한글 이름이 이 조건에 해당할 때 영문 `engName`의 `Title`로 다시 승격하지 않는다. 직접 지정한 개요 수준과 글꼴 폴백은 그대로 판정한다. 개요 이름은 해당 수준을 우선한다. 글꼴 폴백은 첫 비공백 런의 크기를 본문 크기와 비교한다.

본문 크기는 글꼴 폴백 후보의 첫 비공백 런 크기를 0.1pt 단위로 묶고, 문단당 최대 200자의 길이로 가중한 최빈값이다. 머리말·꼬리말·각주·캡션 문단, 실패한 섹션의 문단, `※`·`*`·`주:`·`(단위`로 시작하는 줄은 추정에서 제외한다. 제외한 문단도 제목 수준 판정은 받는다. 유효 문단이 3개 미만이거나 가중 글자 수가 40자 미만이면 기존 13/16/20pt 기준을 사용한다. 본문 추정이 가능할 때 1.1배, 1.25배, 1.5배부터 각각 H3, H2, H1이다. PDF 리더와 같이 120자를 넘는 문단은 글꼴 크기만으로 제목으로 올리지 않는다.
글꼴 후보가 20만 문단 한도를 넘으면 문서 전체에 기존 고정 기준을 유지하고 경고를 남긴다. 한도 앞뒤에 다른 기준이 섞이지 않도록 낮춘 한도의 합성 문서로 확인했다.

이번 수정은 감수자의 독립 라벨에 맞춰 상수를 고른 결과가 아니다. H1 경계 1.5배와 글자 수 상한 120자는 PDF 리더의 기존 규칙이다. 앞선 1.4배 경계는 HWP와 HWPX의 스타일 이름 판정 차이를 가린 값으로 확인되어 되돌렸다. 첫 런 대신 지배 글꼴 크기를 쓰는 변경, 1.1배 비율의 수정, 같은 크기 굵은 제목 규칙은 실물 근거가 더 필요해 적용하지 않았다.

## 독립 PDF 라벨 평가

감수자가 작업자 표본을 제외하고 무작위로 고른 공개 보도자료 34문서의 글꼴 폴백 780문단을 평가했다. HWPX 26문서와 HWP 전용 8문서이며, 원래 라벨의 제목 양성은 84문단이다. 원래 라벨을 그대로 쓰면 최종 수정의 정밀도는 17/18(94.4%)이고 재현율은 17/84(20.2%)다. PDF 16·19·21·23·24쪽을 다시 확인하자 `156783710.hwpx`의 `표제목` 5개가 모두 표 바로 위 캡션이었고, 그중 원래 제목으로 표시한 2개도 캡션이었다. 원본 라벨은 보존하고 `.codex-work/review-overrides-round2.json`에서 그 2개만 본문으로 교정했다. 교정 뒤 제목 양성은 82문단이다. 상수 선택에는 이 라벨을 사용하지 않았다.
부모·앞선 작업의 판정은 라벨에 저장된 수준을 사용하고 현재 수정은 같은 파일을 다시 읽었다. `python -m scripts.probe_heading_review_labels corpus/press-pairs .codex-work/review-opus/labels-auto.json --overrides .codex-work/review-overrides-round2.json`으로 세 판정과 라벨 문단 텍스트 일치를 재확인했다. 교정 전후 집계는 `.codex-work/`의 라벨 JSON에 보존했다.

## 캡션·차례·양식 스타일의 PDF 대조

공개 보도자료 삼중 짝에서 실제 문단에 `표`·`그림`·`차례`·`목차`·`양식`과 `제목`이 함께 든 스타일을 사용한 파일은 HWPX 3개, HWP 0개였다. 선언만 있고 사용하지 않은 `차례 제목` 스타일은 세지 않았다. 아래 20문단은 해당 스타일을 실제로 사용하는 세 파일에서 PDF 렌더의 위치를 눈으로 대조했다. 표제 5개는 표 바로 위에 있었고, 나머지 15개는 도표 안의 분류 라벨이었다. 모두 본문 문단이어야 하며 이번 수정에서 제목 수준 0이었다.

| 칸 | 표본 파일·PDF 쪽 | 정답 근거 | 기대 | 실제 | 판정 |
|---|---|---|---|---|---|
| HWPX 캡션 스타일 | `corpus/press-pairs/156783710.hwpx`·PDF 16·19·21·23·24쪽 | `표제목` 다섯 줄이 각각 수치 표의 바로 위에 있음 | 5개 모두 제목 아님 | 5/5 수준 0 | 일치 |

같은 공개 PDF에서 `156783576` 1쪽, `156783579` 4·5쪽, `156783603` 2쪽, `156783637` 2·3쪽, `156783709` 5쪽, `156783877` 1쪽, `156783930` 5·6쪽도 렌더해 표·그림·상자 표제의 문맥을 확인했다. 이 일곱 문서의 대응 HWPX 문단은 주로 `바탕글` 스타일이므로 위 20문단의 스타일 규칙 검증에는 넣지 않았다. 합계 열 문서의 PDF는 살펴봤지만 **대상 스타일을 직접 검증한 문서는 세 개**다. 요청된 열 문서 조건은 로컬 공개 보도자료 짝만으로 충족하지 못했으며 이 부분은 미검증으로 남긴다. `소제목`·`중제목`을 H1보다 낮출 독립 실물 근거도 이 표본에서 확인하지 못해 수준을 바꾸지 않았다.

## 전체 공개 실물 대조

`a132069`과 `8087ade`의 `dochan/`을 한 번씩 추출해 이번 수정과 같은 입력으로 읽었다. `scripts/probe_heading_relative.py`는 기준 결과를 파이프로 전달하고 문서별 Markdown SHA-256, 문단 경로·제목 수준·오류 목록만 메모리에서 비교했다. 문단의 제목 수준을 임시로 0으로 만든 뒤 Markdown SHA-256을 다시 비교해 제목 외 출력 변화를 확인했다. 전체 출력을 파일마다 저장하지 않았다. 아래 표의 기준은 바로 앞 커밋 `a132069`이다.

| 코퍼스 | 형식·문서 수 | 비교 성공 | Markdown 변경 문서 | 제목→본문 | 본문→제목 | 수준만 변경 | 제목 외 Markdown·문단 경로·오류 변경 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 공개 HWP·HWPX | HWP 5,376 | 5,376 | 45 | 2,007 | 0 | 294 | 모두 0 |
| 공개 HWP·HWPX | HWPX 1,700 | 1,672 | 21 | 32,277 | 0 | 156 | 모두 0 |
| 공개 합계 | 7,076 | 7,048 | 66 | 34,284 | 0 | 450 | 모두 0 |
| 공개 보도자료 | HWPX 346 | 346 | 1 | 45 | 0 | 0 | 모두 0 |
| 공개 보도자료 | HWP 111 | 111 | 0 | 0 | 0 | 0 | 모두 0 |

공개 HWPX 28개는 기준과 수정본 모두 같은 예외로 읽지 못했다. 신규 예외는 0개다. 바로 앞 커밋 대비 HWPX 32,277문단이 제목에서 본문으로 돌아갔다. 이 가운데 `통계표 데이터`가 20,165개, `표제목`이 11,488개다. 최상위 문단의 감소는 234개(5,727→5,493)이며, 나머지는 주로 표·도표 안의 중첩 문단이다. `8087ade`를 기준으로 비교하면 HWPX 본문→제목은 앞선 감수의 12,791개에서 1,027개로 줄었다. 남은 1,027개는 `문서제목` 300개, `제목(소제목)` 156개, `제목1` 131개, `소제목` 114개, 그 밖의 스타일·글꼴 폴백 326개다. `소제목`·`중제목`의 H1 수준을 낮출 PDF 근거가 없어 그대로 두었다. 공개 보도자료 최상위 문단 제목은 이번 수정에서 HWPX 237/7,750→232/7,750, HWP 283/2,970→283/2,970이다. 모든 중첩 문단을 포함한 제목 수와 최상위 문단의 제목 수는 분모가 다르므로 별도로 제시했다.

동일 텍스트의 최상위 문단을 중복 횟수까지 보존한 다중집합으로 맞춰 제목 수준과 제목/본문 상태를 각각 비교했다. 공개 보도자료 HWP↔HWPX 91쌍의 공통 1,962문단은 수정 전후에 수준·상태 모두 1,962개 일치했다. 내부 실물 76쌍의 공통 9,856문단도 수준·상태 모두 수정 전후 9,856개 일치했다. 내부 HWPX와 HWP에서 각각 18개 중첩 제목이 본문으로 돌아갔고 최상위 제목 수는 변하지 않았다. 내부 파일명과 내용은 기록하지 않았다. 내부 157파일의 제목 외 Markdown·문단 경로·오류 변경도 모두 0이다.

## 판정과 남은 한계

두 리더의 이름 있는 제목 스타일 판정이 같아졌고, 글꼴 폴백은 PDF 리더와 같은 H1 경계·길이 상한을 쓴다. 합성 단위 테스트, 공개 PDF 렌더, 공개 전체 코퍼스 및 내부 짝 비교에서 위 범위의 동작을 확인했다. 독립 라벨 교정 후 재현율은 20.7%이므로 같은 크기 굵은 제목과 번호·배치로 구별되는 제목은 후속 실물 검증이 필요하다. 대상 스타일의 PDF 짝이 세 문서에 그쳐 요청된 열 문서 조건을 충족하지 못했다. 첫 런과 지배 글꼴 크기의 차이, 1.1배 경계의 비대칭도 후속 검증 대상으로 남긴다. README는 이 작업에서 수정하지 않았다.
