# HWPX 열기 암호 실물 검증 (2026-10-04)

HWPX의 `META-INF/manifest.xml`은 암호화된 각 파트에 AES-256-CBC, PBKDF2, SHA-256 시작 키와
SHA-256-1K 검사값을 기록한다. 공개 `encrypt.hwpx`의 여섯 암호화 파트를 복호화하여 각 파트의
검사값을 확인했다. 파일 본문은 raw deflate 스트림이며, 끝에는 AES의 16바이트 경계까지
0x00으로 채운 바이트가 2·2·11·8·14·7개 있다. 이 바이트는 deflate EOF 뒤에 있으므로
복원 본문에 포함하지 않는다.

종전의 1,699개는 `hwpx/`의 `.hwpx` 1,675개에 `hwp/`의 `.hwpx` 25개를 더하고
`encrypt.hwpx` 한 개를 뺀 수다. 뒤의 25개는 OLE 서명의 HWP 바이너리이므로 HWPX 파서 회귀에
해당하지 않는다. 종전 1,699개와 1,674개 집계는 모두 `hwpx/`의 `.hwp` 확장자 12개를
누락했다. 이 12개 가운데 11개는 HWPX이고 한 개는 손상 ZIP이다. 이번 측정 때 보도자료
폴더에는 `.hwpx` 352개가 있었고 그중 두 개는 배포용 암호화 파일이었다. 따라서 고정 목록
2,063개 중 비암호화 회귀 집합은 2,061개다.
`encrypt.hwpx`의 암호 `abcde`는 공개 테스트 입력의 값이며, 이 기록은 다른 프로젝트의 구현 코드를
근거로 사용하지 않는다. 지원하는 방식은 위 실물 매니페스트에서 관찰한 조합으로 한정한다.
