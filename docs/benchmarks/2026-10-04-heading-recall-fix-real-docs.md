# 제목 감지 리뷰 수정 실물 검증

## 검증 기준과 판정

`scripts/probe_heading_relative.py`로 공개 HWP·HWPX 7,076개를 문서별로 읽었다. 비교 기준은 절 제목 시험 규칙 이전 커밋과 이번 수정 직전 커밋 두 가지다. 각 파일의 전체 Markdown을 디스크에 저장하지 않고 제목 수준을 지운 Markdown의 SHA-256, 문단 경로, 오류 목록, 제목 수준만 대조했다. HWPX에서 기존부터 읽지 못하는 28개는 두 기준과 현행에서 동일했고 새 예외는 없었다. 글상자 문단은 두 리더가 최상위 흐름에 평탄화하므로 제목 판정 대상이다. 그림 없는 도형의 캡션 문단은 흐름에 남지만 제목 판정과 본문 크기 표본에서는 제외한다.

| 칸 | 표본 파일 | 정답 근거 | 기대 | 실제 | 판정 |
|---|---|---|---|---|---|
| HWP 제목 감지 | `corpus/press-pairs/156783513.{hwp,pdf}` | PDF 4쪽에서 두 네모 표지 줄이 독립 절을 시작한다. | 제목 2문단 | 제목 2문단 | 일치 |

| HWP·HWPX 제목 감지 | `corpus/press-pairs/156784016.{hwp,hwpx,pdf}` | PDF 3쪽에서 네모 표지 3줄이 절 제목이다. | 형식마다 제목 3문단 | 형식마다 제목 2문단 | 각 1문단 누락. 보통 굵기의 본문 주석 문장이 제목과 같은 문단에 있다. |

| HWPX 크기 반올림 | `corpus/hwp-public/hwpx/issue2019_floating_form_74312.hwpx` | 원시 글자 크기 14.02·14.04pt인 변경 문단을 본문 집계의 0.1pt와 같은 기준으로 비교했다. | 같은 14.0pt를 크기 강조로 보지 않음 | 수정 직전보다 제목→본문 74문단 | 표본 문단의 판정 일치. 74문단 각각의 의미 라벨은 없다. |

개발 PDF 판독 표본은 형식마다 24문단 중 양성 15개였고 TP 14·FP 0·FN 1이었다. 대리 라벨 평가 780문단은 TP 46·FP 5·FN 36으로 이번 수정 전과 같았다. 형식별로 HWP 191문단은 TP 7·FP 0·FN 5, HWPX 589문단은 TP 39·FP 5·FN 31이다. 대리 라벨은 PDF 글꼴과 표지에서 만든 값이므로 독립 PDF 의미 판독의 대체물이 아니다. 보류 판독 라벨은 이 검증에 사용하지 않았다.

## 공개 전체와 내부 짝의 전후 비교

| 비교 기준 | 형식·파일 수 | 본문→제목 | 제목→본문 | 수준 변경 | 제목 외 Markdown·문단 경로·오류 변경 |
|---|---:|---:|---:|---:|---:|
| 시험 규칙 이전 | HWP 5,376 | 6,463 | 2 | 0 | 모두 0 |
| 시험 규칙 이전 | HWPX 1,700 | 3,287 | 0 | 0 | 모두 0 |
| 수정 직전 커밋 | HWP 5,376 | 0 | 31 | 0 | 모두 0 |
| 수정 직전 커밋 | HWPX 1,700 | 8 | 74 | 0 | 모두 0 |

수정 직전과 비교한 공개 HWP의 제목→본문 31문단은 5개 파일에서 발생했다. `kreg1.hwp`의 `서.` 번호, 두 금융소득 해설 파일의 순번 밖 한글 표지, `issue2019_floating_form_74312.hwpx`의 근접 크기처럼 실제 변경 문단을 따로 열어 규칙의 입력을 확인했다. 이 변화는 제목 수준에만 한정된다. 공개 보도자료 91쌍의 공통 1,962문단은 수정 전후 모두 전부 일치했다. 내부 문서는 파일명과 내용을 기록하지 않고 76쌍의 공통 9,856문단이 수정 전후 각각 9,856문단 일치했음을 집계했다.

그림 없는 HWP 도형 캡션의 제외는 합성 레코드 테스트로 확인했다. 공개 코퍼스의 이번 제목 변동에서 해당 캡션임을 확인한 문단은 없어, 이 세부 기제의 실물 검증은 미완료다. 책갈피·각주 참조, 순번 14음절, 동일 0.1pt 반올림을 포함한 전체 제목 감지 행은 기존 ✅를 유지한다. 수정 뒤 독립 판독 라벨(26문서 372문단) 점수는 수정 전과 같다(TP 21·FP 4·FN 29) — 고친 오류가 보류 문서에는 나타나지 않았다.
