# HWP·HWPX 제목 스타일 2차 감수 실물 검증

자세한 코퍼스 비교와 독립 PDF 라벨 결과는 [기존 제목 검증 기록](2026-10-04-hwp-heading-relative-real-docs.md)에 남겼다. 이번 감수에서는 스타일 이름에 `표`·`그림`·`차례`·`목차`·`양식`이 들어 있을 때 그 이름만으로 제목을 만들지 않는 규칙을 확인했다. 명시적 개요와 글꼴 폴백은 유지한다.

| 칸 | 표본 파일 | 정답 근거 | 기대 | 실제 | 판정 |
|---|---|---|---|---|---|
| HWP 제목 감지 | 공개 보도자료 짝에서 해당 스타일 사용 HWP 0문서 | PDF 짝의 HWP 스타일 사용 조사 | 대상 스타일을 쓴 문서의 PDF 렌더 대조 | 해당 표본 없음. 합성 단위 테스트는 통과 | 요청된 열 문서 실물 조건은 미검증 |
| HWPX 제목 감지 | `corpus/press-pairs/156783710.hwpx` | 같은 ID PDF 16·19·21·23·24쪽의 표 바로 위 캡션 | `표제목` 5문단 모두 본문 | 5/5 수준 0 | 일치 |
| HWPX 제목 감지 | `corpus/press-pairs/156783678.hwpx` | 같은 ID PDF 2~4쪽의 도표 내부 분류 라벨 | `표안제목` 11문단 모두 본문 | 11/11 수준 0 | 일치 |
| HWPX 제목 감지 | `corpus/press-pairs/156783956.hwpx` | 같은 ID PDF 7쪽의 네 칸 전략 도표 | `도표안 제목 사본1` 4문단 모두 본문 | 4/4 수준 0 | 일치 |

대상 스타일 20문단은 모두 PDF 렌더와 일치했다. 공개 보도자료 PDF를 추가로 7문서 확인했지만, 대응 HWPX 문단은 주로 `바탕글` 스타일이라 규칙의 직접 검증에는 포함하지 않았다. 대상 스타일을 실제 사용한 공개 삼중 짝이 HWPX 3문서·HWP 0문서여서, 요청된 열 문서 기준은 충족하지 못했다.

직전 커밋 `a132069` 대비 공개 HWP 5,376개에서 제목→본문 2,007문단, HWPX 1,672개 읽기 성공 문서에서 32,277문단이었다. 양쪽 모두 본문→제목과 제목 외 Markdown·문단 경로·오류 변경은 0개였다. 독립 PDF 라벨 780문단은 원본 라벨 기준 정밀도 17/18, 재현율 17/84였고, PDF에서 캡션으로 확인한 2건을 교정한 기준으로는 정밀도 17/18, 재현율 17/82였다. 공개 보도자료 91쌍의 공통 1,962문단, 내부 76쌍의 공통 9,856문단은 제목 수준과 상태가 모두 일치했다. 내부 파일명과 내용은 기록하지 않았다.
