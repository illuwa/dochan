# 배치 경로 실물 검증

2026년 10월 4일에 공개 코퍼스와 합성 단위 테스트를 함께 검증했다. 이 작업에는 Supported Elements 표의 특정 요소 칸이 배정되지 않았으므로 새 ✅를 제안하지 않는다. 여기의 통과는 파서의 의미적 정답률이 아니라 기존 배치 출력과 보고서 내용 보존을 뜻한다.

| 칸 | 표본 파일 | 정답 근거 | 기대 | 실제 | 판정 |
|---|---|---|---|---|---|
| 배치 Markdown 출력·보고서 보존 | 공개 혼합 4,600개. POI `ex45698-22488.xls`와 공개 HWP/PDF를 포함한다. 전체 목록은 증거 JSON에 있다. | 기준 커밋 `8d0a246`의 직렬·병렬 출력 SHA-256과 BatchResult 필드이다. | 모든 N에서 4,600개 결과가 일치해야 한다. | N=1·4·8·12·15 및 N=4·15 반복에서 4,600/4,600개가 일치했다. 매번 4,553개 성공·47개 실패였다. | 통과이며 README 요소 칸과는 무관하다. |

코퍼스와 출력 루트 및 snapshot 난수 경로만 정규화했고 출력 자체는 바꾸지 않았다. 수집에 쓴 심볼릭 링크 목록은 입력 허용 정책을 바꾸지 않는다. 세부 측정 조건·메모리 관측 한계·처리량은 [성능 기록](2026-10-04-speed-batch.md)에 있다. 원문 출력은 보관하지 않았고, 파일별 해시 목록은 저장소에 두지 않고 측정 도구로 다시 만든다.
