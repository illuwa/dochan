# HWP·HWPX 양식 개체 표시 글 — 한컴오피스 화면 대조 (2026-10-03)

## 요약

한컴오피스 HWP(Mac) 화면을 정답으로 삼아 양식 개체(명령 단추·선택 상자·라디오 단추·콤보 상자·입력 상자)의 표시 글 규칙 두 가지를 바로잡았다.

- **콤보 상자(HWPX)**: 한컴은 `selectedValue` 와 `displayText` 에 관계없이 **첫 `hp:listItem` 의 `value`** 를 표시한다. 전에는 `selectedValue` 와 같은
  항목의 표시 글을 냈고, `selectedValue` 가 빈 실물(공개 콤보 6개 전부)에서는 아무것도 내지 않았다. 한컴은 HWP 의 `ComboBoxSet Text` 를 HWPX 첫
  항목 값으로 저장하므로(공개 `form-01` 짝), 이제 두 형식이 같은 글을 낸다.
- **단추·선택 상자·라디오 캡션(HWP·HWPX)**: 윈도 단축키 표기처럼 `&&` 는 `&` 로, 단독 `&` 와 끝의 `&` 는 숨긴다. 공개 실물의 `IP R&&D연계` 가 화면처럼
  `IP R&D연계` 로 나온다(공개 HWPX 캡션 45개에 `&` 가 있다). 입력 상자·콤보 상자 글에는 적용하지 않는다.

빈 입력 상자·빈 콤보 상자에 한컴이 보여 주는 컨트롤 이름(붉은 기울임)과 다중 계열 차트의 "차트 제목" 은 문서 데이터가 아닌 UI 자리표시자라 내지 않는다.
비밀번호 입력 상자는 화면에 가림 문자가 보이지만 내용을 내지 않는다(개인정보 보호 결정).

## HWP·HWPX 교차 검증과 변경 범위

공개 코퍼스에서 같은 이름의 HWP·HWPX 짝 중 양식 개체가 있는 실제 짝 3개(`form-002` 180개, `form-01` 5개, `form-02` 5개)의 Markdown 출력이
두 형식 간에 완전히 같다(전에는 `form-01` 의 콤보 상자 1개가 HWPX 에서 빠졌다). `hwp2hwpx-from_*` 은 이름만 같고 내용이 다른 문서라 짝에서 뺐다.

## 공개 코퍼스 분포

공개 HWPX 1,675개 중 12개 문서에 선택 상자 573개(CHECKED 137, UNCHECKED 436), 라디오 6개, 단추 6개, 콤보 6개, 입력 상자 7개가 있다.
미확정(세 번째) 상태는 없다.

직전 커밋 대비 공개 HWPX(양식 개체가 있는 문서)와 공개 HWP 전체 5,383개의 Markdown 해시를 비교하면 7개만 바뀐다: HWPX `form-01`·`form-002`·`form_002`·
`alhangeul-macos-form-002`·`auto-hwp-form-01`·`hwp2hwpx-from_6`, HWP `form-002`. 모두 콤보 상자 또는 `&` 가 든 캡션이 있는 문서다.
