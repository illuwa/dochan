# PDF 각주 — 두 조각으로 그린 위첨자 표지와 글자마다 조각인 정의 줄

이 문서의 표와 3/8 판정은 본문 크기 보정 전의 기준선이다. 현재 판정은 [후속 실물 검증](2026-10-04-pdf-note-body-real-docs.md)에 기록했다.

## 범위와 판정

README `각주/미주 · PDF` 칸은 ⬜ 그대로다. 이번 변경은 각주 복원 규칙을 세 곳 바꿨다.
- 숫자와 닫는 괄호가 따로 그려진 위첨자 표지 `1`·`)` 를, 내용 순서로 이어지고 같은 기준선·크기에서 맞닿아 있으면 한 표지로 본다. 앞에 맞닿은 `(`·숫자가 있는 조각은 표지의 시작이 아니고(`(1)`, `12)` 의 `2)`), 병합에 쓴 조각은 다시 쓰지 않는다.
- 표지가 붙는 본문 글자는 쪽의 최빈 글자 크기의 0.95배 이상이거나, 각주 정의 글자보다 1.1배 이상 크면 된다.
- 정의 줄이 글자마다 조각이면 앞 조각을 이어 붙여 표지를 찾고 그 다음 글자 위치를 내어쓰기 기준으로 쓴다.

구분선 규칙은 더 엄격해졌다. 구분선 후보 바로 위 48pt 안에 같은 폭(양 끝 ±1.5pt)의 가로선이 있으면 좌우 테두리가 없는 표의 하단선으로 보고 거부한다(감수에서 재현한 "표 머리 칸 `증감률1)` + 표 아래 `1) 전년 대비`" 오탐을 막는다).
정의·표지 일대일 대응 조건은 그대로다.

공개 근거는 정책브리핑(korea.kr) 보도자료다(공공누리 제1유형, `python -m scripts.collect_public_press_pairs` 로 받고 `--recheck` 로 같은 이름의 첨부끼리 다시 짝지은 375건).
한컴 PDF 내보내기로 만든 문서라 내부 `test_pairs/` 와 같은 생성 경로이며, 같은 보도자료의 HWPX 각주가 정답이다. 인용한 첨부는 `https://www.korea.kr/common/download.do?fileId=<fileId>&tblKey=GMN` 이다.

합계: HWPX 정답 각주 8개(3문서) 중 3개 복원, 복원한 3개는 렌더와 모두 일치(정밀도 3/3). 놓친 5개는 모두 "쪽의 최빈 글자 크기 = 본문 크기" 가정이 표·그림 글자 때문에 깨진 쪽이다.
이 가정을 바꾸는 일은 내부 음성 77문서의 오탐 0 근거를 다시 세워야 하므로 이번 범위에 넣지 않았다.

## 안전 확인

- 공개 pdf.js PDF 983개: Markdown SHA-256 983/983 불변, 각주 검출 0 → 0.
- 공개 보도자료 PDF 375개(재짝지음 후): 바뀐 문서는 위 두 개뿐이다(각주 0 → 3). 나머지 373개 Markdown 불변.
- 내부 PDF 80개(`test_pairs/`, 이름·내용 비공개): Markdown 80/80 불변, 각주 검출 7 → 7.
- 감수자가 구분선 검사를 꺼 본 실험에서도 공개·내부 1,463문서의 결과가 같았다 — 실제로 오탐을 막는 것은 정의·표지 일대일 대응이다. 표 하단선 규칙은 그 대응이 우연히 맞는 표 주석을 위한 추가 방어다.

## 단위 테스트

`tests/test_pdf_split_note_marker.py` — 맞닿은 두 조각 표지, 떨어진 조각·다른 기준선·다른 크기·사이에 끼인 조각 거부, 숫자만 있는 조각 거부, 글자마다 조각인 정의 줄의 내어쓰기,
쪽 최빈 크기보다 작지만 정의보다 큰 캡션 표지(호스트 완화 고정), 표 하단선 거부와 짧은 단독 구분선 허용, `(1)` 과 `12)` 의 유령 접미 거부, 조각 객체를 바꾸지 않음.
기존 각주 테스트(`tests/test_pdf_notes.py` 등 23개)는 그대로 통과한다.

## 후속 본문 크기 보정

쪽의 조각 최빈 크기 대신 반복되는 긴 줄의 글자 수 가중 크기를 사용하고, 첫 표지의 1.44pt 겹침을 기존 기하 허용오차 안에서 받아들였다. 위 표에서 미통과였던 20쪽의 각주 1개와 3쪽의 각주 4개를 복원해 공개 HWPX 정답 8개를 모두 복원했다. 새 각주의 표지 자리와 정의는 두 쪽을 렌더해 확인했다. 공개 pdf.js 983개와 내부 PDF 80개의 Markdown은 모두 수정 전과 같다. 자세한 판정 근거와 음성 검증은 [후속 실물 검증](2026-10-04-pdf-note-body-real-docs.md)에 있다.
