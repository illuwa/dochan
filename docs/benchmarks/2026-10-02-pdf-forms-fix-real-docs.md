# PDF Form XObject 리뷰 반영 실물 검증

2026-10-03에 공개 pdf.js PDF 983개를 최종 코드로 다시 읽었다. 출력 전체를 문서별로 저장하지 않고 SHA-256, 문자 수, 오류 목록, 문자 조합 빈도만 기록했다. 독립 문자 정답지는 PDFium 텍스트 추출 결과다. 기능 추가 전과 리뷰 직전의 비교 자료, 최종 수치와 39개 표본의 문서별 결과는 `2026-10-03-pdf-forms-real-docs.md`에 함께 남겼다.

`TAMReview.pdf`의 신규 문자 44,856개 중 36,223개(80.75%)는 Unicode 제어문자 또는 U+FFFD다. 이 문자들을 포함한 재현율만으로 읽을 수 있는 본문 품질을 판단하지 않았다. 읽을 수 있는 문자를 제외한 뒤의 조합 재현율과 정밀도를 별도로 기록했다. PDFium 텍스트 추출 결과도 해당 표본의 제어문자를 포함한다.

최종 신규 읽을 수 있는 문자 43,306개와 리뷰 직전의 38,030개 차이 5,276개는 `freeculture.pdf`의 반복 꼬리말 글자 5,280개 증가와 `knockout_groups_test.pdf`의 BBox 밖 글자 4개 제거로 설명된다. 이 수치는 고유한 본문 정보량이 아니다.

리뷰 직전과 최종판의 Markdown·JSON 해시는 각각 983개 중 979개가 같다. 직접 Form 글자가 없는 944개에서는 각각 942개가 같다. 공개 표본 4개의 차이는 `bug1974436.pdf`와 `issue14847.pdf`의 주석 경계 보류, `freeculture.pdf`의 반복 꼬리말 링크 보류에 따른 독립 URL 출력, `knockout_groups_test.pdf`의 BBox 밖 글리프 4개 제거로 분류했다. 마지막 표본에서 변환된 Form BBox의 오른쪽 경계는 해당 글리프 시작점보다 왼쪽에 있다. PDFium 텍스트 추출은 이 글자를 포함하지만 Form 클립 기하상 표시 영역 밖이다.

리뷰 직전 링크 연결 557건 중 기능 추가 전 388건보다 늘어난 169건은 Form 글자 때문이 아니다. 경계 허용 폭을 0.00001pt에서 0.0001pt로 넓힌 것이 원인이며, 그중 165건은 `freeculture.pdf`의 반복 꼬리말 URL이다. 최종판은 기능 추가 전의 0.00001pt 허용 폭으로 돌아갔다. 실물에서 확인한 약 0.000003~0.000006pt 경계 차이는 허용하고, 0.00005pt가 글리프 안으로 들어오는 합성 입력은 보류한다.

내부 79쌍은 Form 글자 문서가 0개다. 따라서 이 결과를 Form 본문의 양성 검증으로 쓰지 않는다. 문서별 비교 지표는 모두 같고, 표 888개·잘못된 머리말/꼬리말 0개·평균 토큰 일치율 0.9754가 유지됐다.

공격 입력 재현은 테스트 안에서 바이트를 조립했다. 자원 사전이 다른 호출자 1,000개가 1 MiB Form을 가리킬 때 스트림 연산자 분석은 1회였다. 자식 Form의 비유한 조각 뒤 순서 번호, 예외 격리, 그래픽 텍스트 상태, 페이지 MCID·Artifact, 중첩 BBox, 200,000개 글자 위치 예산, 거부된 디코드 캐시를 각각 회귀 테스트로 고정했다. 전체 테스트는 4,424개 통과, 29개 건너뜀, 14개 예상 실패이며 Ruff 검사도 통과했다.

## 2차 감수 재검증

직전 커밋과 수정판을 공개 PDF 983개에서 다시 비교한 결과, Markdown과 JSON의 SHA-256 해시는 각각 983개 모두 같았다. 직접 Form 글자가 있는 39개의 문자·2글자 조합 지표도 모두 같아, 위 표의 재현율과 정밀도 수치는 변하지 않았다. 링크 검증은 기본 모드와 `text_tables` 모드 모두 연결 388건·보류 290건·불일치 0건·URL 소실 0건·최종 런 불일치 0건이며, 직전 커밋과 주석별 판정이 같다. 내부 79쌍은 문서별 공통 수치 지표의 다중집합이 모두 같고, 표 888개·잘못된 머리말/꼬리말 0개·평균 토큰 일치율 0.9754를 유지했다.
