# HWP 짝 일치 점검 3차 리뷰의 실물 검증

후속 코드 검토에서 표 앵커가 `□ ` 글머리와 제목 본문을 갈라 놓을 때 앞의 글머리만 20pt 제목으로 승격하는 합성 사례를 발견했다. 글머리만 남은 조각의 글꼴 추정 제목을 막는 실패 테스트와 수정을 추가했다. 아래 실물 쌍 집계는 이 후속 수정 전에 측정한 값이며, 전체 테스트는 수정 후 다시 실행했다.

이 문서는 공개 `corpus/hwp-public`의 같은 이름 HWP·HWPX를 비교한 결과다. 코퍼스 원문이나 변환 전문은 저장하지 않고 SHA-256, 글자 수, 진단과 구조 지표만 `.codex-work/`에 남겼다. HWPX 출력은 짝 비교의 정답 후보이며, 원시 HWP 레코드와 HWPX 원문에 서로 다른 서식이 저장된 경우는 파서 결함으로 단정하지 않았다.

현재 구현 주석은 캡션 방향 필드를 한컴 HWP 공개 명세 표 76으로 지목한다. 이번 워크트리에는 명세 원문이 없어 표의 비트 정의를 독립적으로 다시 읽지는 못했다. 아래 A 판정은 공개 HWP의 원시 속성값과 대응 HWPX 캡션 5개의 일치에 근거한다.

현재 HEAD에서 추출한 소스와 수정본으로 공개 7,076파일의 출력을 각각 측정했다. HWP 132파일만 바뀌었고, JSON 132파일·Markdown 130파일·일반 텍스트 129파일이 바뀌었다. HWPX 1,700파일의 모든 출력은 같았고, 전 형식에서 진단과 예외 변화는 0파일이다. 공개 보도자료 90쌍의 자산 경로 제외 일치는 90/90쌍으로 유지됐다. 내부 76쌍은 파일명·내용을 기록하지 않고 원문 일치 55/76쌍, 자산 경로 제외 일치 57/76쌍이 유지됨을 집계했다.

합성 테스트는 `tests/test_hwp_parity_review_r3.py`의 캡션 속성, 표 셀 각주, 본문 미주 참조, 참조만 있는 문단 사례다. 네 테스트 모두 수정 전에 실패한 뒤 통과했다. 전체 테스트는 `5,444 passed, 36 skipped, 14 xfailed`였고 `ruff check dochan scripts tests`도 통과했다. README는 수정하지 않았다.

## 4차 감수 수정의 실물 검증

### 비교 기준과 출력 계약

2026-10-04에 최신 제목 패치가 적용된 `25d2113`을 4차 이전 기준으로, 감수 대상 `9007ddc`를 결함 재현 기준으로 사용했다. 공개 이름 짝은 611쌍이고 비교 가능한 현재 짝은 574쌍이다. 이전 라운드의 판정을 저장한 지표로 공통 573쌍을 고정했다. 내부 문서는 76쌍의 집계와 숫자 인덱스별 해시만 남겼다.

오케스트레이터의 결정에 따라 글자처럼 취급하는 표만 원시 앵커에서 문단을 나눈다. 떠 있는 표와 머리말·꼬리말은 글자로 투영한 앵커 위치가 0일 때 문단 앞으로 옮기고, 중간 위치에서는 문단 뒤에 둔다. 옮기는 표 앞의 그림·도형·각주 정의는 원시 앵커 순서대로 함께 먼저 출력한다. 수식 블록과 앵커 없는 개체의 기존 출력 계약을 유지한다.

이 선택은 [SUPPORT_NOTES의 떠 있는 표 미해결 항목](../SUPPORT_NOTES.md)과 [백로그 11번](../superpowers/plans/2026-10-02-improvement-backlog.md)에 부합한다. HWPX의 중간 떠 있는 표 분할은 계속 미해결이며, 그 출력에 맞추려고 HWP 문장을 자르지 않는다. 공식 명세 원문은 로컬에 없고 네트워크를 사용할 수 없어 새 규범 근거를 독립 재확인하지 못했다. 속성 DWORD의 위치 4·비트 0과 8 WCHAR 앵커는 기존 리더의 계약 및 공개 바이트 관찰을 재사용했다.

감수 대상과 수정본의 중간 분할 수를 모두 새 프로브로 다시 측정했다. 앞뒤에 출력 본문 조각이 있는 경우를 세면 25/23→0그룹으로 감수와 같다. 인라인 참조·수식이 삽입되기 전 원시 텍스트에서도 앵커 양쪽에 글자가 있는 경우만 세면 17/21→0그룹이다. 최신 제목 패치 때문에 이전 감수의 34,899개와 현재 기준의 34,802개는 분모가 다르다. HWPX 제목 9,344개를 포함한 전체 제목 수도 44,146개로 그대로다. 첫 제목 내용은 책갈피 출력 표지와 공백을 제거한 해시로 비교했고, 변경 공개 566파일은 원문 문자열 해시도 추가로 대조했다. 나머지는 JSON 전문 지문이 같아 원문 문자열도 그대로다. 유일한 원문 변화는 `korea-2011-0430_청년_해외일자리_창출사업_투명집행_방안_권고.hwp`의 `보도자료` 앞 공백 7→6개다. 제목 단어와 수준은 같다.

첫 블록 변화 206파일은 제목→머리말 등 주석 블록 93개, 제목→표 54개, 본문→표 30개, 각주→주석 블록 17개, 본문→주석 블록 12개다. 문서 제목은 같은 내용으로 남지만 첫 Markdown 블록의 종류까지 불변이라고 주장하지 않는다.

변경 566파일은 모두 실제 HWP다. 확장자상 HWP 562개와 HWPX 4개이며 모두 공개 `hwp/` 입력이다. `hwpx/` 1,700파일의 출력은 동일하다. 문단 그룹마다 원시 앵커 순서와 출력 위치도 비교했다. 감수 대상이 새로 만든 그림 1개·도형 24개·각주 정의 1개의 역행을 복원했고, 수정 후 추가 역행은 각 유형 모두 0개다. 여기서는 교차 개체 쌍을 세므로 감수의 개체 묶음 수와 집계 단위가 다르다. 코퍼스에 원래 있던 앵커·레코드 불일치까지 모두 해결했다고 주장하지 않는다.

공백뿐인 조각을 버리는 기존 HWPX 계약 때문에 분할 1,527그룹에서 공백 183자가 제외됐다. 감수 대상의 198자보다 15자 적다. 글자가 있는 조각의 앞뒤 공백은 보존하며 빈 수식 객체는 공백 조각과 구분한다.

### 합성 검증과 재실행

새 테스트 28개 중 감수 대상 소스로 재실행한 21개가 실패했고 수정 후 28개 모두 통과했다. 빈 인라인 수식 4경계, 반대 레코드 순서 2경계, 실제 합성 GSO 그림·도형, 셀 안 중첩 표, 떠 있는 표·머리말의 선두/중간, 책갈피, 공백 조각, 제목 후보 등록, 최종 제목 판정 및 런 예산을 포함한다. 조각 제목 판정 삭제·공백 조각 유지·`defer_heading` 무력화 변이는 모두 테스트 실패로 검출했다.

기존 4차 `_table` 픽스처는 속성 0으로 떠 있는 표를 만들면서 문단 분할을 기대했다. 문단 분할 시험의 의미를 유지하도록 비트 0을 1로 고쳤고 기존 분할 단언은 유지했다. 책갈피 시험의 기존 독립 표지 문단 단언만 수정했다. 해당 단언이 실제 표지만 있는 조각과 가짜 제목 결함을 고정한 근거는 위 실물 표와 감수의 공개 표본이다.

분할로 늘어난 런도 문서 예산에 반영하며 예산이 없으면 런을 그대로 보존하고 해당 블록을 런 뒤로 보낸 뒤 경고한다. 인라인 수식은 변환한 문자열을 한 번 만들어 삽입과 경계 보정에 같이 쓴다. 메모리 안에서 표 8,000/16,000/32,000개를 측정한 결과는 0.249/0.524/1.055초였고, 각각 모든 표와 본문을 보존했다. 32,000개에서 런 예산 집계는 64,001개, 제목 후보는 1개, 경고는 0개였다. 대형 합성 파일은 디스크에 만들지 않았다.

전체 테스트는 Python 3.9에서 5,540개 통과, 36개 건너뜀, 14개 예상 실패다. Ruff도 통과했다. 공유 리더 진입점·출력 모델과 README, SUPPORT_NOTES, 백로그는 수정하지 않았다. 원본 문서와 출력 전문은 저장소에 복사하지 않았다.

새 프로브는 다음과 같이 같은 공개 코퍼스를 기준 소스와 수정 소스로 각각 읽는다. `--private-pairs`를 사용하면 내부 결과는 숫자 인덱스와 해시·집계로만 남는다. `--pair-reference`에는 이전 라운드가 `same_document` 판정을 저장한 JSON을 넣어 공통 분모를 고정한다.

```bash
/usr/bin/python3 -m scripts.probe_hwp_parity_sweep_fix scan corpus/hwp-public \
  --source-root BASELINE --press-pairs corpus/press-pairs \
  --private-pairs test_pairs --output before.json
/usr/bin/python3 -m scripts.probe_hwp_parity_sweep_fix scan corpus/hwp-public \
  --press-pairs corpus/press-pairs --private-pairs test_pairs --output after.json
/usr/bin/python3 -m scripts.probe_hwp_parity_sweep_fix diff before.json after.json \
  --pair-reference previous-pairs.json --output delta.json
```
