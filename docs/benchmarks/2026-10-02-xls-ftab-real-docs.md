# XLS Ftab 전체 표와 실물 수식 재검증

2026년 10월 2일 `illuwa/w-xls`에서 수행했다. 공식 Ftab 전체 데이터 구현은 완료했다. 수식의 일반 지원 칸은 외부 참조·NameX·UDF·배열 상수가 남으므로 **⬜ 유지**를 제안한다. README는 변경하지 않았다. 이 문서는 앞선 `2026-10-02-xls-fix-real-docs.md`의 Ftab 원본 미확보 상태와 수식 집계를 갱신한다.

## 명세 데이터와 생성 규칙

정답은 Microsoft [MS-XLS 2.5.198.17 Ftab](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-xls/00b5dd7d-51ca-4938-b7b7-483fe0e5933b)의 로컬 HTML과 추출 JSON이다. 네트워크는 사용하지 않았다. HTML의 표와 JSON을 각각 파싱한 결과 373개 항목의 번호·이름·문법이 모두 일치했다. 번호는 0x0000부터 0x017B까지의 명세에 기재된 값만 포함하며, 중간 미할당 번호를 채우지 않았다. 0x00FF의 공식 표기는 `User Defined Function`이다.

`dochan/office_binary/xls_ftab.py`는 생성된 이름 373개와 고정 인자 수 210개를 제공한다. 고정 인자가 1개 이상인 193개 함수 집합은 HTML의 별도 `params-fixed` 목록 193개와 정확히 일치했다. 나머지 17개는 명세가 인자 없음으로 지정했다. 선택·반복 인자를 가진 163개 항목은 고정 인자 사전에 넣지 않았다. 원본 해시는 다음과 같다.

| 원본 | SHA-256 |
|---|---|
| `ftab.html` | `03647a076151e4e3c0ad5304bfc5f4902c0378a328548af9594d9bef7ce0441a` |
| `ftab-table.json` | `f30365f746837d0ce65b6ebc4ffb7210d223e8fa62b5b76a373c29ca4db2813d` |

`ref`와 `val`은 각각 스택 피연산자 한 개다. 쉼표는 개수를 더하고 `/`는 대안이며 괄호는 묶음이다. `[x]`는 선택 인자이고 `*N(x)`는 0회부터 N회까지 반복한다. 따라서 `*13(val, val)`은 0~26개이지 13개가 아니다. 문법에서 도출한 최솟값과 최댓값이 같을 때만 PtgFunc용 고정 인자 수를 기록했다. PtgFuncVar는 기존처럼 토큰에 기록된 개수를 사용한다. 문법 해석 규칙은 생성 스크립트의 주석에도 있다.

생성기는 알 수 없는 문법, 중복 번호, 누락된 문법 행, 이름이 다른 문법 행을 거부한다. JSON 2MiB, 문법 4,096자, 중첩 32단계, 계산 인자 수 255개의 상한은 생성 입력의 자원 제한이며 함수 계약을 추정하는 값이 아니다. 런타임의 기존 토큰 길이·오류 개수 상한과 WARN·캐시 보존 경로는 그대로 유지했다. 새 런타임 의존성을 넣지 않았다.

AVERAGE를 고정 토큰의 단일 범위로 읽던 기존 WARN 호환 경로는 유지했지만 공식 고정 인자 표에는 넣지 않았다. UDF의 공식 라벨을 실제 호출 이름으로 오인하지 않도록 기존 `F255(...)`와 WARN을 유지했다. 미할당 함수·미지원 토큰에 대한 기존 구조 보존 정책도 유지했다.

## 비교 모집단과 정규화

공개 POI spreadsheet 디렉터리를 재귀 검색해 동명 XLS/XLSX 36쌍 모두를 검사했다. 하위 디렉터리의 추가 짝은 없었다. 수식이 있는 20쌍에는 텍스트가 있는 원시 `<f>` 219개와 공유 템플릿을 상대좌표로 확장한 후속 셀 851개가 있으며, 합계 1,070개를 대조했다. 나머지 16쌍은 수식 표본이 없으므로 통과 표본으로 세지 않았다. 프로브 예외는 0개였고, 이번 표 변경으로 기존 정확 일치가 불일치로 바뀐 셀도 0개였다.

| 비교 단계 | 변경 전 | 변경 후 |
|---|---|---|
| 정확한 문자열 일치이다. | 832/1,070개, 77.76%이다. | 974/1,070개, 91.03%이다. |
| 공백 정규화를 포함한 일치이다. | 834/1,070개, 77.94%이다. | 1,027/1,070개, 95.98%이다. |
| 따옴표 시트 이름·함수 접두 정규화의 추가 일치이다. | 이전에는 별도 측정하지 않았다. | 0개이다. |
| 절대참조 표시 정규화의 추가 일치이다. | 이전에는 별도 측정하지 않았다. | 0개이다. |

공유 수식 확장 셀을 제외하고 **텍스트가 있는 `<f>` 219개만** 대조하면 정확 일치 175개(79.91%), 표기 정규화 포함 일치 192개(87.67%)이다. 공유 후속 셀을 포함한 95.98%만으로 원시 수식의 지원 폭을 과장하지 않는다. 이번 측정은 수식 문자열에 관한 것이며 캐시 값 일치율을 다시 측정한 결과가 아니다.

공백 정규화는 문자열 리터럴·따옴표 시트명·대괄호 식별자를 보존한 채 산술·비교 연산자와 인자 구분 쉼표 주변, 여는 괄호 직후, 닫는 괄호 직전의 공백만 제거한다. `A1 B1`, `SUM(A1) B1`, `A1 (B1)`, `(A1) (B1)`의 참조 교차 공백은 보존한다. 이전 프로브가 괄호 밖 교차 공백이나 구조화 열 이름의 공백까지 없앨 수 있던 결함을 합성 실패 테스트 후 수정했다. 실제 53개 추가 일치는 `FormatChoiceTests` 51개와 `MatrixFormulaEvalTestData` 2개에서 나온다.

시트명 정규화는 `!` 앞의 단순 영문·숫자·밑줄·점 이름이나 동일 형태의 시트 범위에 붙은 바깥 작은따옴표만 제거한다. 함수 접두는 함수 호출 위치의 `_xlfn.`만 제거하며 리터럴이나 UDF의 이름 인자는 건드리지 않는다. 절대참조 정규화는 문자열·시트명·대괄호 밖의 A1 참조에서 `$`만 제거한다. 이는 같은 셀에서 가리키는 위치의 비교이며, 복사 시 상대·절대 참조 의미까지 같다고 주장하지 않도록 별도 지표로 분리했다. `F255(_xlfn.COUNTIFS,...)`를 `COUNTIFS(...)`로 바꾸거나 외부 통합문서의 이름을 삭제하는 정규화는 하지 않는다.

정확 일치하지 않은 96개 중 53개는 공백 차이다. 나머지 43개는 아래 일곱 범주로 모두 분류했으며 미분류는 0개다. 원본 차이가 있는 셀도 전체 분모에서 빼지 않았다. 프로브 JSON에는 셀 좌표, 기대·실제 식, 원시 FORMULA 토큰, ARRAY 템플릿과 해당 토큰을 단독 해석한 경고를 기록했다.

## 단위 테스트와 회귀

`tests/test_xls_ftab.py`의 합성 테스트는 공식 번호별 대표 함수, 선택·반복 문법, 잘못된 생성 입력, UDF 경고, 고정 함수 210개 × 토큰 클래스 3종의 바깥 피연산자 보존, 정규화의 음성 사례와 원시 레코드 근거 추출을 검증한다. 새 테스트가 구현 전에 실패하는 것을 확인했다. 기존 미지 함수·미지원 토큰·가변 인자 구조 테스트도 유지했다.

기존 `test_parse_biff_workbook_preserves_unknown_fixed_formula_functions`가 사용하던 251은 공식 Ftab의 0x00FB `RESUME`이다. 해당 테스트의 `F251` 기대는 누락된 표를 정상 동작으로 고정하고 있었다. 미지 함수 경고·구조 보존이라는 테스트 의도를 지키기 위해 가변 함수 픽스처와 기대를 실제 미할당 번호 249 및 `F249`로 바꿨다. 고정 함수 250의 기존 캐시·WARN 단언은 바꾸지 않았다. 251이 정상적으로 `RESUME()`로 해석되는 별도 테스트도 추가했다. 이번 후속에서 다른 기존 테스트 단언은 변경하지 않았다.

공유 모델·출력·라우팅 파일 변경은 없다. 수식 표시 계약은 기존 XLSX와 같은 `캐시 (=식)` 또는 `=식`이며 새 출력 모델을 만들지 않았다. README·CHANGELOG·AGENTS·패키지 메타데이터·잠금 파일도 변경하지 않았다.

전체 테스트는 **2,023 passed, 24 skipped, 14 xfailed**였으며, 신규 합성 테스트 54개와 생성기 재현 검사 및 `git diff --check`도 통과했다. 건너뜀과 예상 실패를 통과로 계산하지 않았다.

## 재현

저장소 루트에서 다음 명령을 실행한다. 코퍼스와 명세 원본은 읽기 전용이며 저장소로 복사하지 않는다.

```bash
/usr/bin/python3 -m scripts.generate_xls_ftab corpus/specs/ftab-table.json dochan/office_binary/xls_ftab.py --check

git diff --check
```
