# HWP 짝 일치 점검 3차 리뷰의 실물 검증

이 문서는 공개 `corpus/hwp-public`의 같은 이름 HWP·HWPX를 비교한 결과다. 코퍼스 원문이나 변환 전문은 저장하지 않고 SHA-256, 글자 수, 진단과 구조 지표만 `.codex-work/`에 남겼다. HWPX 출력은 짝 비교의 정답 후보이며, 원시 HWP 레코드와 HWPX 원문에 서로 다른 서식이 저장된 경우는 파서 결함으로 단정하지 않았다.

현재 구현 주석은 캡션 방향 필드를 한컴 HWP 공개 명세 표 76으로 지목한다. 이번 워크트리에는 명세 원문이 없어 표의 비트 정의를 독립적으로 다시 읽지는 못했다. 아래 A 판정은 공개 HWP의 원시 속성값과 대응 HWPX 캡션 5개의 일치에 근거한다.

| 칸 | 표본 파일 | 정답 근거 | 기대 | 실제 | 판정 |
| --- | --- | --- | --- | --- | --- |
| HWP 표/그림 캡션 | `(식량정책관-농업기반과) (보도자료) 장마 속 남부지역 가뭄  농업분야 선제적 총력 대응(7.24 배포시).hwp` ↔ `.hwpx` | HWP 표 캡션 `LIST_HEADER`의 오프셋 8 값은 `0x006f0042`, `0x0065006a`, `0x0000002a` 등이고, 각 값의 하위 2비트는 모두 2이다. HWPX의 대응 캡션 다섯 개는 모두 `side="TOP"`이다. | 캡션 방향은 속성값의 하위 2비트에서 읽는다. | 수정 전 HWP는 TOP 2개·BOTTOM 3개였고, 수정 뒤 HWP·HWPX 모두 TOP 5개다. 이 짝은 자산 경로 제외 Markdown 불일치에서 일치로 바뀌었다. | 통과. 기존 ✅ 유지. |
| HWP 텍스트의 고정폭 빈칸 | `86712_regulatory_analysis.hwp` ↔ `.hwpx` | HWP `PARA_TEXT`의 제어 코드 31이 12개 있고, HWPX `Contents/section0.xml`의 대응 위치에는 문자 그대로 `U+2007`이 12개 있다. | 이 짝의 해당 위치에서 같은 문자가 나온다. | 코드 31을 일괄 `U+2007`로 바꾸면 이 짝은 일치하지만, 기존에 자산 경로 제외 일치하던 다른 공개 짝 208개가 불일치로 바뀌었다. 전역 변경을 되돌렸다. | 이 표본은 미해결. 기존 텍스트 ✅를 이 사례의 통과 증거로 삼지 않는다. |
| HWP 제목 밑줄 | `expense_report.hwp` ↔ `.hwpx` | HWP 제목의 글자 모양 ID 10의 속성값은 `0x2`로 굵기 비트만 켜져 있고 밑줄 비트는 0이다. HWPX의 대응 제목 런은 밑줄 속성이 켜져 있다. | 각 파일에 저장된 서식을 그대로 낸다. | HWP는 굵게만, HWPX는 굵게·밑줄로 나온다. 두 원본의 저장 속성이 다르므로 HWP 밑줄을 만들어 넣지 않았다. | 파서 결함으로 재현되지 않음. |
| HWP 각주/미주 | `footnote-01.hwp` ↔ `.hwpx` | HWP에는 각주 `CTRL_HEADER`가 9개 있으며 하나가 표 셀 안에 있다. HWPX도 각주 9개이고 세 번째 정의는 표 셀 안의 각주다. | 표 안 각주를 셀의 기존 `Footnote` 모델에 보존한다. | HWP 각주 8→9개, 해당 짝의 원문 Markdown이 완전 일치로 바뀌었다. | 통과. 기존 ✅ 유지. |
| HWP 각주/미주 참조 번호 | `3-09월_교육_통합_2022.hwp` ↔ `.hwpx` | HWP 첫 본문 문단의 `PARA_TEXT`에는 제어 코드 17과 `en  ` 컨트롤 ID가 있고, HWPX에는 대응 미주 참조가 있다. 양쪽 미주 정의는 46개다. | 본문 안에 `[1]` 참조를 두고 미주 정의와 같은 번호를 쓴다. | 수정 전 HWP 본문 `[1]`은 0개였고 수정 뒤 1개다. 전체 미주 참조는 HWP·HWPX 모두 46개다. 머리말과 첫 본문 문단의 순서는 여전히 달라 이 짝의 Markdown 전문은 일치하지 않는다. | 참조 번호 통과, 전문 일치 미완. 기존 ✅ 유지. |

현재 HEAD 소스와 수정본의 공통 비교 대상 573쌍에서 원문 Markdown 완전 일치는 145→147쌍, 자산 경로 제외 완전 일치는 434→443쌍, 일반 텍스트 완전 일치는 231→234쌍이다. 기존에 자산 경로 제외 일치하던 434쌍은 모두 유지됐다. 새로 제목·길이 필터에 들어온 1쌍이 있어 최종 비교 대상은 574쌍이며, 최종 자산 경로 제외 일치는 443/574쌍이다. 공통 573쌍의 각주 개수 일치는 572→573쌍, 표 서명 일치는 8,956/8,967개 그대로다. 남은 차이의 원인 전체를 확정한 수치는 아니다.

현재 HEAD에서 추출한 소스와 수정본으로 공개 7,076파일의 출력을 각각 측정했다. HWP 132파일만 바뀌었고, JSON 132파일·Markdown 130파일·일반 텍스트 129파일이 바뀌었다. HWPX 1,700파일의 모든 출력은 같았고, 전 형식에서 진단과 예외 변화는 0파일이다. 공개 보도자료 90쌍의 자산 경로 제외 일치는 90/90쌍으로 유지됐다. 내부 76쌍은 파일명·내용을 기록하지 않고 원문 일치 55/76쌍, 자산 경로 제외 일치 57/76쌍이 유지됨을 집계했다.

합성 테스트는 `tests/test_hwp_parity_review_r3.py`의 캡션 속성, 표 셀 각주, 본문 미주 참조, 참조만 있는 문단 사례다. 네 테스트 모두 수정 전에 실패한 뒤 통과했다. 전체 테스트는 `5,444 passed, 36 skipped, 14 xfailed`였고 `ruff check dochan scripts tests`도 통과했다. README는 수정하지 않았다.
