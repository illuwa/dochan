# HWP·HWPX 글꼴 제목의 본문 크기 상대 판정 실물 검증

## 범위와 기준

개요 수준과 스타일 이름이 정한 제목, 깊은 개요의 본문 판정, 표 셀의 글꼴 제목 제외는 유지했다. 이 근거가 없는 문단의 첫 비공백 런 크기만 문서 본문 크기와 비교한다. 본문 크기는 대상 문단의 첫 비공백 런 크기를 0.1pt 단위로 묶고, 각 문단의 글자 수를 최대 200자까지 가중한 최빈값이다. 짧은 제목 한 줄이 긴 본문 여러 문단보다 본문 크기를 좌우하지 않도록 길이로 가중했고, 긴 문단 하나가 전체를 지배하지 않도록 가중치에 상한을 두었다. 유효 문단이 3개 미만이거나 가중 글자 수가 40자 미만이면 본문 크기를 식별할 자료가 부족하므로 기존 고정 기준을 사용한다.

추정한 본문 크기의 1.1배, 1.25배, 1.4배부터 차례로 H3, H2, H1이다. PDF 리더의 본문 상대 비교와 공개 보도자료의 14~15pt 본문 대 16~20pt 제목을 참고했다. H1 경계 1.4는 내부 실물 11쌍 각각에서 같은 20pt 문단을 HWP의 명시 스타일이 H1로, HWPX의 1.5배 규칙이 H2로 다르게 판정한 측정 결과로 정했다. 20/14는 약 1.43이다. 이 변경으로 내부 11쌍의 일치가 회복됐고, PDF 표본의 제목/본문 판정은 달라지지 않았다. 특정 문서 ID를 조건으로 쓰지 않았다.

공개 정책브리핑 보도자료는 공공누리 제1유형의 동일 문서 HWP·HWPX·PDF 짝이다. 기준 선택에는 짝수 newsId의 PDF 렌더, 독립 검증에는 홀수 newsId의 PDF 렌더를 썼다. PDFium 렌더를 눈으로 확인해 문서 제목·부제·굵거나 큰 절 제목·`□` 절 제목을 제목으로, 서술 문단·목록 항목·주석을 본문으로 표시했다. 표 셀 안의 큰 문단은 기존 제외 계약을 검증하는 별도 사례이며, 아래 43문단의 정밀도·재현율 분모에는 넣지 않았다. PDF 판정은 글꼴 크기만으로 복원할 수 없는 굵기와 배치를 포함한다.

## 전체 실물 대조

기준 리비전 `968c555e0dc87857e24030f9e7b05029c212065a`의 `dochan/`을 `git archive`로 한 번만 추출해 같은 입력을 두 구현으로 읽었다. 프로브 `scripts/probe_heading_relative.py`는 기준 결과를 파이프로 전달하고 파일별 Markdown SHA-256, 모든 문단의 제목 수준 및 요약만 메모리에서 비교한다. 출력 전체를 파일별로 저장하지 않았다. 제목 이외 변경은 두 모델의 모든 문단 제목 수준을 임시로 0으로 만든 뒤 Markdown SHA-256을 다시 비교했다. 이 방식은 들여쓴 각주 제목과 원래 `#`로 시작하는 문장을 잘못 정규화하지 않는다. 문단 경로 및 오류 목록도 비교했다.

|---|---:|---:|---:|---:|---:|---:|---:|

| 공개 합계 | 7,076 | 7,048 | 3,149 | 92,122 | 5,165 | 7,398 | 모두 0 |

공개 코퍼스에서 비교를 끝내지 못한 HWPX 28개는 기준 구현과 변경 구현 양쪽 모두 같은 방식으로 예외가 발생했다. 신규 예외는 0개다. 공개 보도자료의 최상위 본문 문단 제목 비율은 HWPX 6,712/7,750(86.6%)에서 276/7,750(3.6%)로, HWP 2,317/2,970(78.0%)에서 282/2,970(9.5%)로 바뀌었다. 전체 문단 수에는 표·각주 같은 중첩 문단도 포함하지만 이 비율은 최상위 본문 문단만 센 것이다.

공백을 하나로 정규화한 동일 텍스트의 최상위 본문 문단을 중복 횟수까지 포함한 다중집합으로 맞춰 제목 수준을 대조했다. 공개 보도자료 HWP↔HWPX 91쌍의 공통 1,962문단은 변경 전후 모두 1,962개 일치했다. 내부 실물 76쌍의 공통 9,856문단은 변경 전후 모두 9,793개 일치했다. 내부 문서의 파일명과 내용은 이 기록에 남기지 않았다. 별도 `python -m scripts.compare_hwp_pairs` 실행에서도 내부 76쌍의 평균 토큰 일치율 0.9998, 서식 일치율 1.0, 오류 있는 짝 0을 확인했다. 해당 스크립트에는 제목 판정이 없으므로 앞의 제목 일치를 별도로 측정했다.

## 판정과 한계

HWP·HWPX의 글꼴 기반 제목 규칙은 두 리더에 같은 상대 크기 함수를 적용했고 합성 단위 테스트, 공개 PDF 렌더 및 실물 짝 비교를 통과했다. 명시 개요·스타일 및 표 셀 제외 동작은 기존 테스트에서 유지됐다. 큰 제목이 표 안에 있거나 글꼴 크기는 같고 굵기만 다른 제목은 기존 범위와 이 규칙만으로 복원하지 못한다. 기준 본문 크기를 정할 수 없는 짧은 문서에는 이전 고정 기준이 남는다.
