# PDF 각주 — 두 조각으로 그린 위첨자 표지와 글자마다 조각인 정의 줄

## 범위와 판정

README `각주/미주 · PDF` 칸은 ⬜ 그대로다. 이번 변경은 각주 복원 규칙 두 곳을 넓혔다. 하나는 숫자와 닫는 괄호가 따로 그려진 위첨자 표지 `1`·`)` 이고,
다른 하나는 정의 줄이 글자마다 조각일 때의 내어쓰기다. 표지가 붙는 본문 글자 기준도 바꿨다. 쪽의 최빈 글자 크기뿐 아니라, 각주 정의 글자보다 1.1배 이상 큰 글자도 받는다.
정의·구분선·표지 일대일 대응 조건은 그대로다.

공개 근거는 정책브리핑(korea.kr) 보도자료 PDF 다(공공누리 제1유형, `python -m scripts.collect_public_press_pairs` 로 받은 403건 중 PDF 400개).
한컴 PDF 내보내기로 만든 문서라 내부 `test_pairs/` 와 같은 생성 경로다.

## 안전 확인

- 공개 pdf.js PDF 983개: Markdown SHA-256 983/983 불변, 각주 검출 0 → 0.
- 공개 보도자료 PDF 400개: 바뀐 문서는 위 두 개뿐이다(각주 0 → 3). 나머지 398개 Markdown 불변.
- 내부 PDF 80개(`test_pairs/`, 이름·내용 비공개): Markdown 80/80 불변, 각주 검출 7 → 7.
- 같은 보도자료 HWPX 358개 중 각주가 실제로 있는 것은 2개(`<hp:footNote>` 태그 기준, 구역 속성 `footNotePr` 제외)이고 dochan HWPX 리더가 둘 다 읽는다.
