# PDF 리뷰 반영 실물 검증 (pdf-fix, 2026-10-02)

초기 작업의 수치와 판정을 함께 정정했다. 기능별 원시 객체 근거는
[갱신한 원래 검증 문서](2026-10-02-pdf-real-docs.md)에 남겼다. 이번 작업은 README와 공유 모델을
수정하지 않았다. 실물 원본을 복사하지 않았고, 내부 문서는 집계만 기록한다.

## 최종 판정과 독립성

본문 링크는 공개 983개 전체를 조사하고, 해석된 목적지가 있는 49문서를 검사했다. 수정 전 본문
연결 양성 41문서(외부 목적지 32문서)도 41/41문서 재검사했다. 감수자의 31문서보다 넓은 범위다.
연결한 18문서의 주석 87건은 87/87건 일치해 조건부 일치율 100%였고, 경계 오류는 0건이다.
678개 주석 중 보류 591건은 성공에 포함하지 않는다. 보류 중 552건에는 글자가 있고 39건에는
독립 기준의 글자가 없다. 본문 연결의 전체 재현율 100%를 주장하지 않으며 ⬜ 유지를 제안한다.

PDFium의 실제 글리프 상자 중심을 원시 Rect 또는 QuadPoints로 선별한다. 글리프 폭을 제품의
기본값으로 다시 추정하지 않는다. PDFium의 비유니코드 표지 2건만 독립 pdfminer 좌표로 교차
검사한다. 두 도구는 로컬 검증용이며 제품 의존성이 아니다. 비교는 공백 제거와 NFKC 정규화를
사용한다. 동일 대상의 여러 주석도 각각 기록하므로 87은 고유 URL 수가 아니다.

기본 모드와 text_tables 모드의 49문서 모두 Markdown·plain text·JSON을 비교했다. URL 소실과
최종 연결 런 불일치는 각 모드에서 0건이다. 반복 머리글·바닥글 제거와 각주·표 변환 후에도
일반 최상위 문단에서 URL 보존이 확실한 경우에만 페이지 끝 fallback을 생략한다.

전체 링크 프로브의 나머지는 Link 없는 898문서, Link는 있으나 목적지를 해석하지 못한 9문서,
해석 불가 26문서와 15초 시간초과 1문서다. 시간초과는 `pr6531_2.pdf`이며 수정 전 양성 41문서에는
들어 있지 않다. 주석·세로 프로브는 5초 제한을 사용하므로 분모를 섞지 않는다.

별도의 5초 구조 검사 기반 음성 본문 프로브는 Link 없는 896문서를 모두 읽었다. 본문이 있는
599문서와 없는 297문서에서 본문·fallback 오연결은 각각 0건이며 전체 읽기 실패도 0건이다.
이 음성 결과를 양성 링크의 정밀도 근거로 사용하지 않는다.

## 실행과 한계

재현 프로브는 모두 코퍼스 경로를 인자로 받는다. `probe_pdf_link_boundaries`의 `--text-tables`로
옵션 모드를, `--baseline`으로 원래 양성 모집단의 포함 여부를 검사한다. 초기 양성 스냅샷은
기존 전체 패치를 HEAD 소스에 적용한 격리 사본에서 같은 프로브로 얻었다. 표본 파일을 사본에
복사하지 않았다. JSON 원시 결과는 `.codex-work/pdf-fix-*.json`에 있다.

전체 테스트는 지정 명령으로 1,968 passed, 24 skipped, 14 xfailed였다. 기존 HEAD 테스트 단언은
수정하지 않았다. 이전 미커밋 주석 테스트의 폰트 픽스처만 암묵적 500 폭에서 명시적인 Widths로
바꿨으며, 단언은 유지했다. 기본 폭을 실제 글리프 폭처럼 취급하던 잘못된 전제를 제거한 것이다.

V4의 최상위 Length가 없으면 활성 CF의 바이트 단위 길이를 사용하고, AESV2의 CF 길이도
없으면 고정128비트로 처리한다. V5는 고정256비트다. 잘못되거나 충돌하는 CF 길이는 거부한다.
이 변형들은 합성 테스트로 검증했으며 공개 암호 7개는 기존 회귀 표본이다.

packed TIFF의 4MiB 1비트 합성 입력은 같은 장비에서 약 8.61초에서 0.26초로 줄었다. 이는
1,048,576 샘플 예산으로 완성 행까지만 처리한 결과이며 전체 복원 속도나 실물 처리율을 뜻하지
않는다. R6 SASLprep의 이모지 호환성과 순수 Python AES 성능, 비빈 R2·확장 PDFDocEncoding 암호,
EarlyChange 0·packed/16비트 TIFF와 스트림 RC의 실물 검증은 남아 있다.
