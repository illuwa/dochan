# HWPX 차트 종류 확장과 제목·데이터 실물 검증 (2026-10-03)

## 요약

HWPX 차트 추출이 분리 원형(`ofPieChart`)·주식형(`stockChart`)·표면형(`surfaceChart`·`surface3DChart`)·거품형(`bubbleChart`)을
저장 캐시 표로 낸다. 전에는 이 다섯 종류를 `unsupported_type` 경고와 함께 건너뛰었다. 범주(`c:cat`)가 없는 계열도 이제 버리지 않고,
한컴오피스 화면처럼 같은 그림 영역의 범주를 빌리거나(없으면 1부터 번호) 값을 낸다. 공개 HWPX 코퍼스의 차트 82개 전부가 독립 XML 정답과
같아져 README `차트 제목/데이터 · HWPX` 를 ✅ 로 올린다.

정정: 이 기록의 첫 판은 "82/82 차트, 191계열"이라고 적었으나, 비교 프로브가 dochan 과 같은 방식으로 범주 없는 계열 2개를 정답에서 빼고 있었다.
Opus 감수가 독립 정답(193계열, 1,718칸)으로 이를 잡았고, 범주 없는 계열 처리를 고친 뒤 아래 수치로 다시 쟀다.

## 표본과 정답 근거

- 표본: 공개 HWPX 코퍼스(`corpus/hwp-public/hwpx`, 1,675개) 중 차트 파트가 있는 41개 문서, 차트 82개(본문 참조 82개, 고아·중복 없음).
- 데이터 정답: dochan 과 별개로 표준 라이브러리 ElementTree 로 각 차트 XML 의 `c:ser` 를 `c:order` 순으로 읽고,
  `c:tx`(이름), `c:cat`/`c:val` 또는 `c:xVal`/`c:yVal`(거품형·분산형)의 문자열·숫자 캐시를 `c:pt/@idx` 순으로 모은 값.
  범주 없는 계열은 아래 한컴 실측 규칙(같은 그림 영역의 첫 범주, 모두 없으면 1..n)으로 정답을 만든다. 값 캐시가 없는 계열은 0개다.
- 한컴오피스 HWP(Mac) 화면 확인(창 단위 캡처):
  - 공개 문서 2개: `2차원원형.hwpx`(제목 글자 없는 단일 계열 → 계열 이름 "판매" 가 제목), `3차원누적세로막대형.hwpx`(다중 계열 → UI 자리표시자 "차트 제목").
  - 통제 표본 2개(`3차원누적세로막대형.hwpx` 의 XML 만 바꿈): 첫 계열의 `c:cat` 만 지우면 축 이름은 다른 계열의 "항목 1~4" 이고 그 계열 막대도 그려진다.
    모든 계열의 `c:cat` 을 지우면 축 이름이 1~4 다.

## 단위 테스트로만 검증한 것

- 거품 크기 열(`크기`): 공개 거품형 표본에 `c:bubbleSize` 가 없다. 숫자 아닌 크기 캐시는 열 없이 `unsupported_cache`, 길이가 다르면 빈칸과 `length_mismatch`.
  HWPX 표 머리글은 기존대로 한국어(`범주`·`X`·`크기`)이고 DOCX·PPTX·XLSX 의 긴 표 머리글(`Bubble size`)과 다르다.
- 분산형·거품형에서 `c:xVal` 이 없으면 X 를 1부터 번호로 채운다(공개 표본 0개).
- 한 그림 영역에 여러 차트 종류를 섞은 혼합 차트와 다단계 범주는 여전히 표를 내지 않는다(공개 코퍼스에 0개).

## 재현

공개 실물 통합 테스트(`tests/test_hwpx_chart_integration.py` 의 실물 사례)는 저장소 루트에 `corpus/` 가 있을 때만 돈다. 코퍼스를 연결해
실물 사례를 포함한 130개가 통과했다.
