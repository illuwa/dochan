## 수정 근거와 경계

암호 사전은 보안 핸들러 초기화 전에 CF, 하위 필터 사전, StmF/StrF 선택자와 그 내부 값을
간접 참조가 남지 않도록 해소한다. ISO 32000-1의 간접 객체 의미와 공개 표본의 실제 객체
관계를 근거로 했다. 원본 캐시는 수정하지 않는다. 순환을 검출하고 깊이 32와 방문 노드
4,096개로 확장을 제한한다. 이 숫자는 자원 보호 상한이며 규격상 문서 제한이라고 주장하지 않는다.
잘못된 그래프는 문서 전체 예외 대신 기존 암호 경고로 남긴다. V4 최상위 Length가 있는 경우와
없는 경우 모두 합성 암호문이 같은 평문으로 복호화되는지 검증했다.

표의 셀 문자열과 서식 런이 같은 조각 묶음의 시작점을 이용해 열을 정한다. 열 경계를 넘는
조각도 원래 셀에 남는다. `Twentycharacterslong Spill`의 Spill, 붙어 있는 숫자의 마지막 글자,
굵게와 링크 런을 보존하며 새 모델이나 출력 형식을 만들지 않았다. `tracemonkey.pdf`의
`extensively: 3d-cube, 3d-`도 완전히 남는다.

각주에는 기존에 관찰된 줄간격이 있을 때만 하단 60pt 진입을 허용한다. 글자 크기, 내어쓰기,
줄간격, 페이지 하단 경계 검사와 기존 한 줄 정의 뒤 독립 바닥글 방어는 유지한다. 제공된
연속 각주 합성 PDF의 3문단이 모두 각주 안에 들어가며 페이지 번호 바닥글 재현의 흡수는 0건이다.
위치와 간격만으로 구분 증거가 없는 두 줄 각주 등은 보수적으로 남긴다.

packed TIFF의 기존 1,048,576샘플 예산은 스트림별 지역 변수에서 문서별 공유 객체로 옮겼다.
본문·xref·이미지 해제 경로가 같은 예산을 쓰고 캐시 적중은 다시 차감하지 않는다. 문서 간
예산은 독립적이다. 이미지 직접 해제의 우회를 막기 위해 PDF 이미지 함수에 선택 콜백을
추가했다. 부족한 경우 완성된 행까지만 반환하고 `doc.errors`에 경고를 전달한다.
8/16비트와 PNG predictor의 기존 계산은 유지한다.

지정된 20스트림·87,823바이트 합성 재현은 같은 환경에서 수정 전 5.01초, 수정 후 0.28초였다.
한 스트림은 4MiB 영 바이트를 압축하고 Predictor 2, Columns 8000, Colors 1,
BitsPerComponent 1을 지정한다. 전후 한 번씩 측정한 제한 동작이며 전체 복원 속도나 실물
처리율로 해석하지 않는다. 두 실행 모두 연산 한도 경고를 반환했다.

## 프로브의 분모와 음성 대조

새 `scripts/probe_pdf_polish.py`는 코퍼스와 기준 저장소 경로, 표 목록을 인자로 받는다.
기준 코드와 현재 코드는 별도 Python 프로세스에서 불러온다. 암호 검사는 모든 PDF를 분모에
남기고, 파서 실패나 시간초과는 미검증으로 기록하며 성공률에서 조용히 빼지 않는다.
빈 코퍼스와 빈 표 목록도 실패한다. 최초 40초 제한에서 시간초과한 `auth-event-ef-open.pdf`,
`encrypted-attachment.pdf`, `pr6531_2.pdf`는 180초로 재시도해 모두 판정했다.

수정 전 통합 HEAD를 비교 대상으로 실행하면 `issue7665.pdf`에서 복호화 실패와 본문이 빈
문자열로 바뀌는 두 회귀를 검출한다. 표 음성 대조에서는 기준 대비 11파일·114자, 같은 버전의
옵션 끄기 대비 13파일·136자 손실을 검출했다. 재감수의 9파일과 수치가 다르므로 이를 그대로
대체하지 않는다. 이번 측정은 Markdown 전체 길이가 아니라 비공백 문자별 빈도를 비교해
다른 문자의 증가가 누락을 가리지 못하게 한다. 제어문자도 공백이 아니면 센다.

집계 대상은 문단, 셀, 머리글·바닥글, 각주의 실제 텍스트이다. `provenance.path="annots"`인
합성 링크 문단과 `type="comment"`인 코멘트는 본문이 아닌 주석 메타데이터이므로 제외한다.
이는 기준 리더가 URL을 별도 문단으로 추가하던 구현과 Comment가 Footnote를 상속하는
모델 관계에 근거한다. 실제 본문에 연결된 링크의 표시 글자는 그대로 센다. 이 경계도 단위
테스트로 고정했다. 처음 정제 전 나타난 합성 URL 길이 차이는 원문 손실로 세지 않는다.

## 테스트와 재실행

신규 암호·표·각주·predictor 회귀 테스트에서 수정 전 실패를 확인하고 수정 후 통과했다.
표의 PDFReader→Markdown 합성 테스트도 수정 전 코드에서 Spill 누락을 검출했다.
프로브에는 반복 문자 수, 복호화 실패, 빈 출력, 시간초과, 없는 표본, 빈 분모와 주석
메타데이터 경계를 검증하는 테스트가 있다. 기존 테스트의 단언은 변경하지 않았다.

최종 전체 테스트 명령과 결과는 다음과 같다.

```text
/usr/bin/python3 -m pytest tests/ -q -p no:cacheprovider --basetemp=.codex-work/pytest-tmp
2569 passed, 24 skipped, 14 xfailed in 106.64s
```

실물 프로브는 다음과 같이 다시 실행한다. 기준 코드는 git archive로 추출한 코드 사본이며
실물 PDF를 그 사본에 복사하지 않는다. 표 목록은 아래 표본 열의 66개 공개 파일명으로 만든다.

```text
/usr/bin/python3 -m scripts.probe_pdf_polish /Users/illuwa/dev/personal/dochan/corpus/pdfjs-src/test/pdfs --baseline-repo .codex-work/baseline-785c0e0 --table-manifest .codex-work/table-manifest.txt --timeout 180 --workers 4 --output .codex-work/pdf-polish-probe.json
/usr/bin/python3 -m scripts.probe_pdf_features /Users/illuwa/dev/personal/dochan/corpus/pdfjs-src/test/pdfs --output .codex-work/pdf-polish-filters.json
```

원시 집계는 `.codex-work/pdf-polish-probe.json`, 음성 대조는
`.codex-work/pdf-polish-negative-tables.json`, 필터 비교는 `.codex-work/pdf-polish-filters.json`,
최종 전체 테스트 로그는 `.codex-work/pytest-final.log`에 남겼다. 이 경로들은 커밋하지 않는다.
