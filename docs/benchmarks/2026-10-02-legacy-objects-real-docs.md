`Bug50936_1.doc`의 네 대표 기대값은 fnTEXT를 잃고 있었다. 최종 기대값은 `\overline{\text{x}}`, `\text{s}_{\text{unexp}}^{\text{2}}`, `s^{\text{2}}(y)`, `\text{s}_{\text{unexp,ln}_{\text{i}}}^{2}`이다. 이 파일은 25개 저장소 중 16개를 변환하고 반복 배치를 포함해 18곳에 출력한다. MTEF5 실물이 미검증이라는 최초 설명은 더 이상 유효하지 않으며, `37625.ppt`의 두 개체가 통과했다.

기존 DOC·PPT 연결 계약은 유지했다. DOC는 EMBED 구분자의 CPicLocation을 ObjectPool ID로 쓰고, PPT는 최신 PersistDirectory와 ExObjRefAtom을 연결한다. 차트는 기존 Paragraph·Table, 수식은 기존 Equation 모델로 출력한다. 실패하면 기존 미리보기를 유지한다. 내장 Excel은 활성 차트 여부를 먼저 확인하고 기존 워크북 파서로 내부 BRAI를 해소한다. 외부 파일을 열거나 수식을 재계산하지 않는다.

U+EB01·EB02·EB04는 명시적 공백으로 정규화했지만 공백 종류별 정밀 폭은 미검증이다. MTEF 명세 원문을 로컬에서 찾지 못했고 네트워크를 사용하지 않았다. 전체 MTEF 지원이나 명세 전체 대조 완료를 주장하지 않는다. README와 의존성은 변경하지 않았다.
