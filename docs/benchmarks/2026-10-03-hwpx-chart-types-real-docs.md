# HWPX 차트 종류 확장과 제목·데이터 실물 검증 (2026-10-03)

## 요약

HWPX 차트 추출이 분리 원형(`ofPieChart`)·주식형(`stockChart`)·표면형(`surfaceChart`·`surface3DChart`)·거품형(`bubbleChart`)을
저장 캐시 표로 낸다. 전에는 이 다섯 종류를 `unsupported_type` 경고와 함께 건너뛰어 공개 차트 82개 중 9개의 데이터가 빠졌다.
공개 HWPX 코퍼스의 차트 82개 전부가 독립 XML 정답과 같아져 README `차트 제목/데이터 · HWPX` 를 ✅ 로 올린다.

## 표본과 정답 근거

- 표본: 공개 HWPX 코퍼스(`corpus/hwp-public/hwpx`, 1,675개) 중 차트 파트가 있는 41개 문서, 차트 82개.
- 데이터 정답: dochan 과 별개로 표준 라이브러리 ElementTree 로 각 차트 XML 의 `c:ser` 를 `c:order` 순으로 읽고,
  `c:tx`(이름), `c:cat`/`c:val` 또는 `c:xVal`/`c:yVal`(거품형·분산형)의 문자열·숫자 캐시를 `c:pt/@idx` 순으로 모은 값.
  한컴오피스가 저장한 캐시이므로 화면의 데이터와 같다.
- 제목 정답: `c:chart/c:title/c:tx` 의 서식 있는 글자 또는 캐시 값. 제목 요소는 있으나 글자가 없는 차트는 한컴오피스 HWP(Mac)로 열어
  화면을 확인했다(단일 계열 원형 `2차원원형.hwpx`, 다중 계열 막대 `3차원누적세로막대형.hwpx`).

## 재현

공개 실물 통합 테스트(`tests/test_hwpx_chart_integration.py` 의 실물 사례)는 저장소 루트에 `corpus/` 가 있을 때만 돈다. 이번 검증에서는
코퍼스를 연결해 실물 6건을 포함한 127개가 통과했다. 전체 테스트는 4,396 passed, 29 skipped, 14 xfailed.
