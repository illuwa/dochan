## 5-B 중첩 표의 독립 트리 (분리형)

**전제조건 실측.** HWPX 중첩 표 66개(13개 문서) 가운데 PDF 에서 "채택된 표의 단일 셀 안에 분리된
괘선 성분"으로 나타나는 것은 82개, 그중 행·열이 정답과 같은 것은 24개였다. 66개 중 27개는
1×1 글상자형이라 PDF 에 괘선이 없고, 나머지 일부는 부모 셀 테두리와 선을 공유해 한 성분으로
합쳐진다(연결형). 연결형을 "한 굵은 셀에 갇힌 국소 선"으로 추정하는 휴리스틱도 측정했으나 정답
일치가 24 → 26 으로 2건 늘어나는 동안 중첩 표가 없는 66개 문서에서 오탐 211건을 만들어
채택하지 않았다(병합 셀 표의 부분 선을 중첩으로 오인). 설계 문서의 목표 70% 는 "부모 bbox 안의
성분" 289개라는 느슨한 대리 지표에서 나온 것이었고, 실제 도달 상한은 24/66(36%)이다.

**구현.** 괘선 연결 성분을 포함 관계로 트리화한다. 어떤 채택 표의 단일 셀(병합 영역) 안에
완전히 들어가는 성분은 그 셀의 중첩 표가 되고, 셀 경계를 걸치면 부모의 내부 괘선으로 본다.
텍스트는 안쪽 표부터 배정해 한 번만 소비하고, 셀 안에서는 y 순서로 문단과 중첩 표를 배치한다.
중첩 후보는 텍스트 셀이 있고(텍스트 셀 ≥2, 셀 ≥4, 또는 30×12 이상의 1×1) 채택하거나, 텍스트가
없어도 3×3 선 이상·6셀 이상의 빈 서식 격자면 채택한다. 거부된 노드의 채택된 자식은 조부모 셀
(없으면 최상위)로 올린다. 조각은 y 정렬 색인으로 후보 bbox 범위만 잘라 넘기고, 페이지당 후보
1,000개·깊이 32·페이지 5만/문서 20만 셀 상한을 둔다(예산은 채택 시점에 차감).

**결과.** nested_match 24/66 = 0.364(상한 24 를 모두 회수), pdf_nested 25(정답에 없는 1개는
계약규칙 문서), signature_match 0.620 → 0.649, cell_hit 0.902 → 0.912. 문서별: 직원근무평정규칙
6/6, Trade and Security 3/3, 자율준수 3/3, 인권경영 2/2, 보안업무 3/22(대부분 1×1 글상자),
이해충돌방지제도 2/7(연결형), 나머지 6개 문서 각 1/1.

**한계.** 괘선 없는 1×1 글상자, 부모와 테두리를 공유하는 연결형 중첩 표는 복원하지 않는다.

## 5-C 페이지에 걸친 표 병합

**전제조건 실측.** 앞 페이지의 마지막 표 아래에 본문이 없고 다음 페이지의 첫 표 위에 본문이 없는
경우 15건 가운데 열 경계(1.5pt)가 같은 것은 3건(모두 `(260319) 차세대 전략물자관리시스템 개편 홍보
추진 계획(안)` — p6→7, p8→9, p17→18)이며 내용상 진짜 연속(행 번호 2→3→4, "① 로그인"→"② 수출허가")
이었다. 나머지 12건은 열 구조가 다르다. 진짜 연속 3건의 "표 하단 ~ 본문 하단" 여백은 12·34.5·80pt
였고(80pt 는 다음 행이 커서 넘어간 경우), 열 수가 같았다면 오병합됐을 후보의 여백은 414·259pt 였다.

**구현.** 꼬리·머리 표는 위치(가장 낮은/높은 표)로 고른다. 꼬리 표 아래에 본문이 없고(꼬리말 영역
60pt 제외) 머리 표 위에 본문이 없으며(머리말 영역 제외, 본문 상단에서 페이지 높이 12% 안에 시작),
열 경계가 모두 1.5pt 안에서 같고, 꼬리 표 아래 남은 공간이 `max(다음 데이터 행 높이 + 1.5, 페이지
높이의 12%)` 이하일 때만 뒤 표의 행을 앞 표에 이어 붙인다. 반복 제목 행은 첫 행 셀의 최대
row_span 높이만큼 통째로 비교해 버린다(빈 행끼리, 제목 행만 있는 표는 제외; 열 병합만 쓰는 2단 제목의
둘째 행은 우연히 같은 데이터 행과 구조로 구별할 수 없어 남긴다 — 데이터 손실보다 제목 중복이 낫다). 셀은 원래 페이지
provenance 를 유지한다. `/Rotate` 90·270 페이지는 병합하지 않는다.

**결과.** 진짜 연속 3건 병합(pdf_tables −3), 열 구조가 다른 12건은 그대로, signature_match
0.644 → 0.646. 페이지 경계에서 잘린 셀(앞 행과 뒤 행이 같은 셀의 앞·뒤)은 두 행으로 남긴다.

## 5-D 세로쓰기·회전 텍스트

**전제조건 실측.** 79쌍 343,896개 텍스트 조각 중 회전 조각은 0개다. 실물 검증 자료가 없어 PDF
32000 §9.4.4 텍스트 행렬 모델과 합성 픽스처(90° CTM 세로 열 두 개, 회전 표 머리글, 180° 텍스트)로
검증했다.

**구현.** 조각에 장치 공간의 쓰기 축 벡터(dir_x, dir_y)를 두고 ltr/rtl/down/up 으로 분류한다.
줄 조립은 방향이 같고 줄 간 좌표(가로쓰기 y, 세로쓰기 x — 전통 세로쓰기는 오른쪽 열이 먼저)가
허용오차 안일 때만 같은 줄로 묶고 줄 안은 쓰기 축 순으로 정렬한다. 표 셀 배정 기준점은 쓰기
축·수직축으로 회전해 계산한다.

**결과.** 79쌍 지표는 이전과 완전히 동일(가로 문서 무변화). README 의 세로쓰기 표시는 실물 문서를
확보해 검증하기 전까지 올리지 않는다.

## 5-E 괘선 없는 표 (실험적 옵션, 기본 꺼짐)

**전제.** 선 없음 표는 기하 근거가 없어 텍스트 시작 위치의 반복만이 단서이고, 정답지(HWPX)에 '선 없음'
속성이 남지 않아 이득을 직접 잴 수 없다. 오탐(글머리 목록·2단 레이아웃이 표로 둔갑) 비용이 크므로
기본 출력은 바꾸지 않고 옵션으로만 제공한다: `PDFReader(text_tables=True)`, `Dochan(..., pdf_text_tables=True)`,
`dochan convert --pdf-text-tables`, `compare_pdf_pairs --pdf-text-tables`.

**구현.** 인접 조각은 먼저 칸으로 합친다(간격이 공백 폭의 2배 미만이면 같은 칸 — 자간을 벌린 라벨이
글자별 열이 되지 않게). 연속 3줄 이상이 각각 2개 이상의 칸을 갖고, 칸 시작 x 군집 중 60% 이상의 줄이
맞는 열이 2개 이상이며 모든 줄이 그중 2열 이상에 닿을 때 표로 본다. 첫 열이 번호·기호 표식(`1.`, `가.`,
`①`, `•`)이거나 같은 한 글자이거나, 둘째 열 이후에 서로 다른 텍스트가 2개 미만이면 목록으로 보고
제외한다. 열은 처음 세 줄에서 확정하고 이후 줄은 적중만 검사한다(선형 시간). 열 20·행 500·그룹
5,000줄 상한. 표로 소비한 줄은 본문에서 빠지고 표는 첫 줄의 그리기 순서에 놓인다.

**결과(79쌍).** 옵션 꺼짐은 이전과 완전히 동일. 켜면 표 886 → 894(+8, 4개 문서)이고 토큰 유사도·
셀 일치율·표 구조 일치·결합 정확도는 모두 그대로다(관문 감수에서 지적된 자간 벌린 라벨의 글자별
열 쪼개짐과 본문 문장 오탐을 칸 병합·목록 제외로 없앤 뒤의 값; 그 전에는 +15 에 토큰 유사도 −0.0008).
정답지에 '선 없음' 속성이 없어 이득은 미측정이며 README 표시는 올리지 않는다.

## 리뷰 반영

각 단계는 codex 독립 리뷰와 Opus 감수를 거쳤고(총 codex 5회·Opus 4회), 브랜치 전체에 최종 관문 리뷰를 한 번 더 돌렸다. 반영한 주요 지적: 중첩 후보마다 전체 조각을
훑어 5,000개 상자 페이지에서 8초가 걸리던 성능 회귀(조각 색인·후보 상한으로 0.2초), 빈 성분이 셀
예산을 선점해 뒤의 진짜 표를 밀어내던 회귀, 거부된 중간 노드의 채택된 자식 유실, 페이지 걸침의
가장자리 근접 조건 부재(열이 같은 다른 표가 페이지 중간 공백을 넘어 합쳐지던 경로), 다중 행 반복
머리글, 거대 정수 MediaBox 로 페이지가 통째로 사라지던 경로, 머리말/꼬리말 영역에만 있는 표가 음수
거리로 병합 조건을 통과하던 경로, /Rotate 180, 좌우 반사 행렬의 기준점 부호, 여백의 세로 라벨 하나가
가로 문단 병합을 꺼버리던 회귀, 글자 단위 Tj 세로 열이 셀 안에서 흩어지던 문제.

**알려진 한계.** 페이지가 5만 셀 한도 근처일 때 거부된 중간 틀의 잠정 예약이 같은 페이지의 뒷 후보를
밀어낼 수 있다(실문서 영향 없음). WMode 1(Identity-V) 세로 폰트는 미지원이며 회전 CTM 만 다룬다.
