# PPTX 레이아웃·마스터 상속 검증 정정

2026-10-03 리뷰와 Microsoft PowerPoint(Mac) 실측에 따라 기존 상속 해석 및 기대값을 정정했다. 최신 판정과 재현 표는 [리뷰 반영 실물 기록](2026-10-02-pptx-master-fix-real-docs.md)에 있다.

기존 기록의 544개 공개 PPTX와 7,793개 런 “독립 대조 100%”는 당시 구현 해석과의 일치였다. PowerPoint 표시 정답을 입증한 수치가 아니며, 해당 문구를 정정한다. otherStyle의 자유 글상자 상속, 조상 안내 문단 pPr/defRPr 상속, 가까운 defPPr 우선 가정은 PowerPoint 실측과 충돌하므로 철회한다.

새 검증은 PPTX 544개와 PPTM·POTX·PPSX 12개를 포함한 556개이다. PowerPoint 실측 deck1 11개·deck2 17개 문단은 합성 재현과 원본 덱 읽기에서 모두 일치했다. XML 프로브는 대응 가능한 7,851개 런에서 구현 해석과 일치했으며, 모호한 389개와 공백 32개를 제외했다.

리뷰 기준 HEAD `7cd4042` 대비 20개 파일의 255개 런에서 크기가 달라졌다. 본문 텍스트·런 개수·런 순서별 텍스트 변화와 Markdown 변화는 모두 0이다. 밑줄 및 위·아래첨자의 공개 양성 상속 실물은 여전히 미검증이다. README의 지원 표는 수정하지 않았다.
